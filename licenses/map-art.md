# Map artwork

Map markers use selected native 16×16 sprites from the free collection of
[Raven Fantasy Icons](https://clockworkraven.itch.io/raven-fantasy-icons)
by Clockwork Raven, plus original Rivet symbols in the same palette.
Names are recorded in `map-art-sources.json`; usage terms are retained in
`Raven-map-markers.txt`. Artwork is not recoloured by the marker's frame colour.

Map tools use 50 selected 16×16 sprites from
[1-bit Pixel Icons](https://nikoichu.itch.io/pixel-icons) by Nikoichu, CC0 1.0.
Names and adaptations are recorded in `map-tool-sources.json`.
The tool atlas retains integer pixels and is tinted using the UI action state.
