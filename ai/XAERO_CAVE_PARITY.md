# Проверка пещерной карты — 2026-10-09

Эталон: локальные Xaero World Map 1.46.0 и Minimap 26.5.0 для NeoForge 1.21.1.
Предыдущие утверждения о полном совпадении были необоснованны: тесты проверяли
собственные допущения реализации. Поведение сверено по настройкам и коду эталона;
чужие исходники в проект не включаются, зависимость на Xaero не добавляется.

| Параметр | Эталон | Исправление Rivet |
| --- | --- | --- |
| Тип | Off / Layered / Full; Layered по умолчанию | Такой же выбор, отдельный тип новых измерений |
| Top Y | Auto или число, применяется сразу | Убраны Apply и высота игрока; Auto/пустая строка |
| Автоматика карты | Minimap / Off / 1×1 / 3×3 / 5×5 | Добавлены все значения, Minimap по умолчанию |
| Автоматика миникарты | Off / 1×1 / 3×3 / 5×5 | Независимая, 3×3 по умолчанию |
| Глубина карты | 1–64, начальная 30 | Исправлен диапазон; нижняя граница top + 1 − depth |
| Освещение по глубине | Выключено | Исправлено начальное значение и формула по выбранному Y |
| Таймер | 1 s, диапазон 0–10, шаг 0.1 | Интервал между переключениями, не ожидание устойчивого кандидата |
| Пещерный zoom миникарты | 2×, диапазон 1–4 | Добавлен множитель поверх сохранённого масштаба |
| Показ Top Y | Включён | Отдельная настройка |
| Ручной режим миникарты | Клавиша + Y | Отдельное состояние и назначение в управлении |

Глубина и освещение общие для встроенной пары карт: у эталона с использованием
тайлов World Map эти настройки миникарты перенаправляются в World Map.
Явно сохранённые старые значения глубины/освещения не сбрасываются при миграции.

Выборка Layered ждёт воздуха/жидкости, а не любого неполного блока. Full сначала
проходит под пригодный грунт, игнорируя растения/горючие/заменяемые блоки.
Учтён небесный свет; пустые обследованные столбцы отделены от неизвестных.
Освещение пересчитывается при движении Top Y внутри одного диапазона и смене
настроек без очистки видимых текстур. Меню выбора сохраняет контекст карты.

Границы соответствия: интерфейс использует модальное окно Rivet UI Kit;
числовые диапазоны представлены выбором и нативным полем, не ползунками Xaero.
Исчерпывающее совпадение всех настроек Xaero и пиксельное сравнение двух модов
на одинаковом мире не подтверждены. Формат v3 сохраняет исходные цвета, свет и прозрачность каждого слоя, поэтому
освещение нескольких прозрачных материалов пересчитывается без повторной выборки.
Старые v1/v2 читаются совместимо; их составной RGB сохраняется до повторной выборки
клиентского чанка. Нативные проверки не выдавать за доказательство полного
визуального совпадения шейдеров.
