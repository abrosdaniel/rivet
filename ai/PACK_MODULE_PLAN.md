# Серверный модуль сборки

Разрешено пользователем: реализация, один JAR, модуль основы; выпуск отложен.
Minecraft/NeoForge/Rivet устанавливает игрок. GitHub не требуется. Одна сборка,
необязательные компоненты с сохранённым выбором, дополнительные клиентские моды
разрешены. Текущая установка, не отдельный профиль. Нет вводимой владельцем версии
и команды отката. Публикация явная, снимки неизменны; активация сейчас либо при
запуске. Подключённые игроки не отключаются. Загрузка публичная.

Транспорт: отдельный TCP-порт по умолчанию 25567; TLS 1.3 с автоматически созданной
идентичностью и явным TOFU подтверждением, без внешних сертификатов/HTTPS-прокси.
Обнаружение через Minecraft status до соединения для игры; поддержка публичного
порта/адреса. Запасной адрес для прокси отложен пользователем; сейчас обнаружение только через status.

Папка подготовки rivet/pack, настройки pack.toml, локальные файлы и ссылки на
конкретные Modrinth/CurseForge файлы через адаптеры; ограничения источников не обходить.
Конфиги missing по умолчанию, replace пофайлово; личные файлы защищены. Только
управляемые файлы удаляются; конфликты требуют обзора. Докачка и лимиты, 0 без лимита.
Повторный запуск через лаунчер вручную; помощник общий, применяется после закрытия.

Этапы:
- [x] Описание и локальная публикация, конфиг сервера.
- [x] Обнаружение status и защищённая раздача; подтверждено на упакованном сервере.
- [x] Клиентское сравнение, компоненты, доверие и применение.
- [x] Адаптеры источников, проверки зависимостей.
- [x] Тесты, документация, проверка реального клиента/сервера.

Старая система удалена полностью: GitHub-каталог, repository/project policy,
семена/template/registry, lock-схемы, сценарий CI и инструменты публикации семян,
экраны каталога и связанные тесты. Общий helper/transactions/cache и обновление
самого Rivet сохранены; пользователь это явно подтвердил.
Серверный и клиентский код компилируются, сборка JAR и тесты core/tooling проходят.
Проверены реальные TLS, докачка, публикации, сохранение файлов, статусы Minecraft.
Полный пользовательский сценарий клиента проверяется отдельно; это ещё не объявляется готовым выпуском.
Адаптеры Modrinth/CurseForge и проверка зависимостей реализованы; запасной адрес отложен.

Нативный клиент также запущен в отдельной папке: проверка меню и политик модулей прошла, ошибок загрузки mixin не было.

Проверка источников: настоящий FerriteCore с Modrinth получен и опубликован,
контрольная сумма и клиентские зависимости проверены. CurseForge проверен
транспортными fixtures (ключ, ограничения, отсутствующая ссылка, контрольные суммы);
настоящего API-ключа для живой проверки нет. Владельцу нужен ключ в переменной
окружения, он не передаётся клиенту. Ни выбор случайной версии зависимости,
ни обход запрета стороннего распространения не реализовывать.

Полный клиентский сценарий: доверие → компоненты → обзор → загрузка → helper
после завершения процесса → следующий запуск → вход в мир. Проверено с настоящим
файлом FerriteCore, сохранением личного конфига и сохранением доверия к серверу.
Отдельный упакованный сервер выполнил новую публикацию Modrinth, передал status
и отдал снимок по TLS, после чего корректно остановился.

## Download priority
Published provider files use the exact public CDN URL first, with size/SHA-256
verification and server snapshot fallback. Local files are server-only. This
supersedes the earlier server-only client distribution implementation. Pack wire
protocol 2 advertises URL support; cancellation never triggers fallback.
