## Перед публикацией

Нужны релизный коммит и успешная полная CI-матрица именно этого коммита.
Текущие изменения незакоммичены, GitHub CI для них не подтверждён.
Push в main с новой версией запускает публикацию автоматически; он не выполнялся.
Windows, полная пользовательская сборка,100 игровых JVM и многочасовой soak
не подтверждены. Платформенные предупреждения9 библиотек остаются открытыми
по решению сохранить один JAR. Установленный профиль/JAR и production не менялись.
