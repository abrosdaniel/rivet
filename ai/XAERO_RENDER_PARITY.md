# Отрисовка карты: сверка с Xaero

Ориентир: World Map 1.46.0 и Minimap 26.5.0 для NeoForge 1.21.1,
проверенные профили и описания параметров автора. Не объявлять полный пиксельный
паритет без сравнительных снимков одной сцены с одинаковыми ресурсами.

Источники: https://chocolateminecraft.com/update.php?mod_id=2,
https://chocolateminecraft.com/update.php?mod_id=0,
https://github.com/thexaero/xaero-minimap-translations/blob/main/en_us.lang.

| Параметр | Эталон / начальное значение Rivet |
| --- | --- |
| Цвета блоков | Точные текстурные, 0 |
| Освещение | Включено; время/погода, свет блоков, ambient измерения |
| Глубина рельефа | Включена |
| Склоны | Направленные, 2 |
| Смешивание биомов | Включено |
| Биомные цвета в стандартной палитре | Выключено |
| Цветы, цветное стекло, тонкие блоки | Включено |
| Редстоун, прозрачность (параметры Minimap) | Включено |
| Миникарта | Квадратная, непрозрачная, масштаб 1 |
| Пещеры | Отдельная матрица XAERO_CAVE_PARITY.md |

Ручные ночной/биомный/высотный режимы предыдущего этапа не являются настройками
эквивалентного базового рендера Xaero. Убраны из UI; устаревшее display.view
не определяет отрисовку. Общая отрисовка Rivet применяется к обеим картам и PNG.

Небесный и блочный свет хранятся раздельно для грунта и прозрачных слоёв (тайл v5).
День/ночь/погода меняют только цветовой кеш без повторного обхода блоков.
Свет отключён — полная яркость; глубина и склоны остаются отдельными настройками.
Чтение v1–v4 сохранено. На старых колонках неизвестный свет оценивается по имеющимся
данным до повторного посещения, без удаления исследования.

Ограничения сравнения: не проверены одинаковые пиксели всех ресурспаков и модовых
моделей. Смена настроек выборки (палитра, растения, прозрачность, тонкие блоки)
пересканирует только доступные клиенту чанки: удалённые сохранённые поверхности
обновятся при посещении. Отключение смешивания биомов обрабатывает стандартные
растения/воду; произвольный BlockColors стороннего мода может сам смешивать tint.
Rivet имеет общую настройку освещения двух карт; Xaero допускает раздельную.
