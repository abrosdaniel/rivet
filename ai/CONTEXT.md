# Действующий контекст Rivet

Обновлено 2026-10-14. Этот файл заменяет накопленный журнал промежуточных этапов.
Инструкции — AGENTS.md; текущая архитектура — ../docs/development/modules.md.

## Продукт и границы

- Minecraft1.21.1, Java21, NeoForge стабильной ветки21.1 от21.1.250.
  Проверять зависимости выбранных модов относительно установленного загрузчика.
- Один устанавливаемый JAR для клиента и сервера. Внутренние bootstrap, helper,
  core и mod не являются отдельными продуктами/установщиками.
- PostgreSQL обязательна для серверных функций даже при выключенном Auth.
- Модульность означает независимые жизненные циклы и владельцев ресурсов;
  выключение функции сохраняет её данные и прекращает её фоновые запросы.
- Автоматические адаптеры: LuckPerms, Plasmo Voice, Simple Voice Chat, Waystones,
  spark, Create: Access Denied. Без ручных opt-in переключателей интеграций.
- Не добавлять публичный Core API без конкретного внешнего потребителя.
  Идеи новых модулей торговли/логистики/журнала мира владельцем не приняты.

## Карта: окончательные решения

- Самостоятельная карта Rivet, миникарта и навигация — единый модуль.
  Рабочей зависимости/адаптера Xaero нет; допустим только импорт актуальных
  форматов меток Xaero/JourneyMap. Старый JSON JourneyMap не нужен.
- Исследование, тайлы, личные метки и личные территории — у клиента.
  Общий обмен исследованной местностью отменён; не возвращать его.
- Личные территории разрешены последним решением владельца. Территории
  объединений остаются отдельными, с правами объединения и неизменяемым
  названием, равным названию объединения. Контур замыкается кликом по первой
  вершине после минимум3 точек, не Enter; палитра квадратами.
- Личная метка отправляется в общий чат; клик/подтверждение создаёт независимую копию.
- Публичные объекты: отдельные draft/published, модерация; изменения снова требуют
  одобрения, до него показывать прежнюю версию. Автор сразу отзывает публикацию.
  Лимиты50/автор и8192/сервер, ревизии/пагинация/deltas ограничены; исследование
  не передавать. Данные выключенных модулей не показывать в слоях карты.
- Waystones отображает только доступные игроку камни по API, без телепортации
  и открытия неизвестных точек; изменение публичности отслеживается.
- Радар показывает головы мобов/игроков, использует модуль скинов; предметы,
  яйца и подобные сущности не нужны. Компас локализован; квадратный — по периметру.
- Настройки карты отдельные, в общей стилистике; пещеры — самостоятельный раздел.
  Размер/позиция HUD редактируются в общем редакторе, без дублирующих настроек.
- Инструменты: остановить активную навигацию, к игроку, создать метку, список
  меток, приблизить, отдалить, слои, территории, линейка. Шестерёнка отдельно снизу
  слева; список меток/линейка не дублируются в ПКМ. Слои общие для обеих карт.
- Видимость позиции по умолчанию — вся карта/все игроки; ограничения приватности
  применяются сервером до передачи данных. Навигация без поиска пути и таймера,
  до прибытия или ручной остановки. У задач может не быть места назначения.
- rivet.map.teleport — отдельное contextual LuckPerms право, включая wildcard
  и явный deny. OP2 сохраняет доступ; rivet.admin не заменяет это право.
  Проверять при исполнении. На поддерживающем сервере не обходить отказ через /tp.
- Ориентир поведения — Xaero, реализация собственная. Пиксельный паритет не обещать.
  Конкретные сверки: XAERO_CAVE_PARITY.md и XAERO_RENDER_PARITY.md.

## Чат и интерфейс

- Один серверный выключатель чата; TAB, имена и остальные функции независимы.
- История: общий канал всем; объединения только действующим участникам, включая
  сообщения до вступления; локальный только прежним онлайн-получателям рядом.
  После выхода из объединения его история не загружается. Архив ограничен.
- Упоминания, [item], команды статусов и отдельный мессенджер исключены.
- Пользоваться общим UI Kit; профиль/настройки/формы — диалоги, без произвольной
  замены потоков интерфейса. My Tasks — ориентир геометрии. Drag-and-drop для порядка.
- Общие настройки находятся последним пунктом меню, не в профиле; кнопка Minecraft
  в настройках не нужна. Поиск/прокрутка не должны создавать пустую вложенность.
- Значки карты — Nikoichu1-bit CC0; не менять порядок существующего атласа.

## Сборки и обновление

- Владелец публикует неизменяемые снимки из rivet/pack; GitHub-каталог сборок удалён.
  GitHub остаётся источником обновления самого Rivet. Сборка не получает отдельной
  вручную вводимой версии. Запасной адрес обнаружения для прокси отложен.
- TLS1.3, отдельный порт, TOFU-подтверждение. Для точных Modrinth/CurseForge файлов
  сначала CDN, затем серверный fallback с проверкой хеша; отмена без fallback.
- optional=false — обязательный видимый компонент с name/description; дополнения
  группируются с основным модом, самостоятельные библиотеки не приписывать ему.
  Не удалять и не менять состав пользовательского pack.toml по своим предположениям.
- Личные файлы защищены, удаляются только управляемые; missing/replace пофайлово.
  Helper применяет изменения после выхода JVM, запуск лаунчером вручную.
- Не заменять установленный Prism/JAR, профиль и production без отдельного поручения.
  Не удалять pending/locks ради обхода защиты запуска; использовать штатное восстановление.
- Новые настройки мигрируют с комментариями/backup и сохранением значений владельца.
