# Аудит патча2.2.1 — 2026-10-14

## Объём

Проверены критические пути и границы модулей: сохранение/отрисовка карты,
публикации и права; меню/пагинация/кэш/отмена запросов; задачи/доступ к складам;
чаты/получатели/история; скины/необязательные адаптеры; очереди/остановка модулей;
pack/bootstrap/helper; состав JAR, локализация и CI/release pipeline.
Это просмотр критических реализаций плюс общие и native регрессии, не доказательство
отсутствия ошибок в каждой строке и во всех сочетаниях сторонних модов.

## Найденное и исправленное

| ID | Проблема | Исправление / доказательство |
|---|---|---|
| P01 | После reconnect карта собирается с нуля; плохой sky свет сохраняет пятна | Локальные previews и восстановление direct sky поверхности; предыдущие проверки в VALIDATION_2026_10_14.md, включено в патч |

| P03 | CoalescingTasks после Error задачи или исключения обработчика ошибок оставляет scheduled=true; новые черновики больше не исполняются | Два теста сначала падали, затем прошли; флаг освобождается, ожидающие операции сохраняются для следующего запуска |
| P04 | Disabled lifecycle fixture не отключал карту и не проверял историю чата | Карта выключена в конфиге fixture; проверки world identity, chat store/worker и их освобождения |
| P07 | Изменение styleEpoch отбрасывает загруженный с диска preview; попытка чтения уже отмечена и не повторяется | Preview сохраняется до новой композиции независимо от поколения освещения; детерминированный native тест обновляет освещение при удерживаемом colour worker (до исправления падает) |
| P06 | Закрытие публикации во время отправки теряло ответ сервера | Закрытие ждёт завершения mutation; чтения можно отменять, отключение модуля по-прежнему закрывает окно; native проверка Close сразу после Submit |
| P05 | Рабочие заметки считают2.2.0 неопубликованной | Проверен GitHub API: releasev2.2.0 и run38490395393 успешны; кандидат повышен до2.2.1 |

не обнаружено. Не изменять пользовательский pack, профиль или production.
