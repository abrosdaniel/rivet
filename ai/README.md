# Рабочая информация агента

Эта папка содержит внутренние инструкции и контекст для работы над Rivet.
Она не является пользовательской документацией и не включается в поставку мода.

Перед работой читать:

1. [Правила проекта](AGENTS.md).
2. [Принятые решения](CONTEXT.md).
3. [План модульной архитектуры](MODULARITY_PLAN.md), если задача касается архитектуры.
4. [Идеи будущих модулей](FUTURE_MODULES.md), если задача касается новых возможностей.

Обновлять заметки при принятии новых решений. Завершённые задачи не считать
доказательством готовности следующей версии. Не хранить секреты и машинные логи.
Публичные инструкции находятся в README, SERVER_GUIDE, CONTRIBUTING и docs/.
