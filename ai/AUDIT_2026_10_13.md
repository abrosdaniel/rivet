# Аудит актуального Rivet — 2026-10-13

## Объём и порядок

Владелец поручил сначала единый план, затем исправления. Не менять установленный
JAR, пользовательские данные и production-сервер. Все проверки — в изолированных
выходах сборки и тестовой БД. Незакоммиченные изменения предыдущих этапов сохраняются.

Это аудит границ модулей и критических путей, а не доказательство отсутствия
ошибок в каждой строке или во всех сочетаниях сторонних модов. Старые результаты
не считаются новым прогоном. Реестр дополняется при новых воспроизведениях.

## Матрица охвата

- Карта/пещеры/радар/локальные метки: поколения репозитория, write-back/retry,
  индексация, готовность света, reset, новые территории и публикации. B01–B06.
- Навигация/права: command tree, повторная серверная проверка, fallback, LP,
  модульные ограничения. B07; реальный native сценарий уже существует.
- Меню/HUD/настройки: RequestSession, MenuTransport/Pages, ownership запросов,
  перевод/композиция, вложенные диалоги. B04 и существующие native full-flow тесты.
- Задачи/склады: сериализация по ключу, поколения callbacks, SQL блокировки,
  revisions, доступ к задачам/контейнерам. Проверяются core/mod/PostgreSQL наборами.
- Объединения/события/голосования/жалобы/уведомления: dispatch READ/WRITE,
  серверные права и SQL-транзакции, outbox, время и повтор команд; общие тесты.
- Чат/Auth/скины/профиль/TAB: лимиты очередей, connection identity,
  group membership lease на время replay, остановка workers, fallback.
- Модули/адаптеры: ModuleRuntime rollback, reverse stop, OptionalIntegration
  fail-closed и сброс, автоматическое подключение интеграций.
- PostgreSQL/протокол: пул, timeouts, ограничение community connections,
  advisory/row locks, пагинация, payload, журнал команд. B01–B03.
- Pack/bootstrap/helper: commitState без изменения файлов, prepare/apply locks,
  pending/recovery, hash/preconditions, safe paths, диапазон loader.
- Конфигурация/импорт/локализация: пределы, сохранение настроек, форматы,
  RU/EN каталоги и существующие тесты.
- CI: матрица unit/SQL/native, проверка markers, артефакты ошибок. B05.

## Результаты

Все B01–B08 исправлены. B04 подтверждён цепочкой RequestSession/transport owner:
во время чтения следующей страницы переход к описанию теперь недоступен; native
проверены обычные modal/Escape переходы. Искусственная задержка сети для этого
конкретного клика отдельно не воспроизводилась.

- Исходный принудительный core/helper/bootstrap/mod/PostgreSQL набор успешен.
- Финальный принудительный прогон: core 524, PostgreSQL 228 (7 штатных пропусков,
  221 выполнен), helper 9, bootstrap 5, mod 6; ошибок нет. UI/module composition успешны.
- B01 воспроизводился падающим тестом. Дополнительно обнаружены отступы pretty JSON:
  лимит считается с учётом вложенности и проверяется по целому ответу.
- SQL: 1024 публикации, параллельная публикация между страницами и догрузка изменений;
  максимальные полигоны, частные ревизии, реальное усечение журнала до 8192 записей.
- Native клиент + реальный сервер: публикации в 9 вариантах (default/light/contrast,
  GUI 1/2/3), освещение без block update, LP grant/revoke/wildcard/explicit deny
  без OP и между измерениями, OP teleport с высотой/полублоком/водой/измерениями.
  OP сценарий сначала выявил падение персонажа после телепорта: fixture поддерживает
  creative flight, точные проверки координат сохранены; повторный прогон успешен.
- Python tooling: 32 теста; YAML и зависимости CI jobs валидны. Новая map-network
  проверка включена в обязательные зависимости release; удалённый CI не запускался.
- Индекс территорий совпадает с полным перебором на 200 случайных viewport и 8192+
  контурах. Локальный микрозамер 20000 запросов с одним видимым контуром: 7 мс индекс
  против 823 мс полного AABB перебора. Это не измерение FPS и не обещание такого
  ускорения всего мода.

Ограничения: не выполнены реальные 100 одновременных игроков, Windows/Linux native
прогон, полный перебор сочетаний сторонних модов и текущий GitHub CI. Этот аудит
охватывает границы всех модулей и критические пути; отсутствие других дефектов
не доказано. Версия не менялась, установленный JAR и production не изменялись.
