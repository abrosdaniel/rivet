## Исправления по присланным логам CI

- Windows build: PackSecurityTest обнаружил повторное использование проверки после
  замены файла. BasicFileAttributes недостаточно для гарантированной инвалидации.
  PackObjectVerifier теперь требует fileKey и unix:ctime для попадания в кэш;
  при отсутствии change timestamp, включая Windows, хеш проверяется повторно.
  Это увеличивает дисковое чтение при повторных запросах на таких файловых системах;
  существующие лимиты запросов/соединений сохранены.
- Добавлены тесты изменения содержимого того же размера с восстановленным mtime
  и файловой системы без change timestamp (ZIP provider с восстановленными basic
  timestamps). Последний воспроизводит неоднозначные метаданные независимо от ОС.
- RU/EN UI: ReleaseCorrectionsHarness ожидал старые112 вместо утверждённых96.
  Исправлено ожидание с диагностикой фактического размера, продуктовый default
  сохранён. Другие112 в MinimapArrowHarness — промежуточный тестовый размер.
- Локально выполнены540 тестов core без ошибок/пропусков; обе языковые версии
  native release-corrections прошли63 сцены/343 проверки. Проверены completion
  markers штатным verify_ui_snapshots.py. Все выходы и клиентские профили изолированы.
- Windows runner и новая матрица GitHub CI после исправления не проверены.
  Старый комплект dist/2.2.0 этих изменений не содержит; перед выпуском требуется
  пересборка и успешная матрица точного коммита. Commit/push/publish не выполнялись.

## Карта после повторного входа: уточнение пользователя на 2.2.0

  Прежний тест проверял повторное открытие того же Screen и не подтверждал этот сценарий.
- Добавлен локальный MapPreviewCache с atomic replacement, CRC, фиксированным
  размером страницы64×64, разделением world/player/layer/LOD и лимитом2048+31
  страниц (~33MiB). Это производный кэш, не источник исследования; повреждённые

  предыдущее изображение до фоновой актуализации исходных тайлов.

  Солнце/погода, block light, ambient, глубина и склоны сохранены; cave использует
  фактический сохранённый свет. Legacy baked overlays сохраняют прежний fallback.
