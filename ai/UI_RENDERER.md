# Основа рендера UI

Skia через HumbleUI/Skija 0.143.18 (Skia m143). Пользователь одобрил прототип
и перенос всего UI 2026-11-09; текущая работа — [UI_MIGRATION.md](UI_MIGRATION.md).
Прототип заменён общим UiCanvas, отдельного рендера на каждый экран нет.

Прототип проверен на macOS ARM64: GUI 1/2/3, кириллица, нативные предметы,
модель подключённого игрока и редактирование. Выявленные pixel unpack/sampler
и повторный blur устранены. Замер простой панели не доказывает ускорения всех окон.

Библиотеки для macOS/Linux/Windows x64/ARM64 включаются в JAR. Проверка
наличия ресурсов не равна живой проверке всех этих платформ. Windows требует
icudtl.dat рядом с библиотекой. Font Noto Sans распространяется с OFL.

Источники: https://github.com/HumbleUI/Skija и официальный LWJGL example.
Не возвращать экспериментальные source sets и загрузку библиотек по сети.
