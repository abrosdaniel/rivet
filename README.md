Rivet — мод для Minecraft с NeoForge. Он устанавливает клиентские сборки серверов
и объединяет профили игроков, задачи, события и общение в одном игровом меню.
На клиент и сервер устанавливается один JAR.

## Возможности

- Установка и обновление сборок с выбором необязательных компонентов и проверкой файлов.
- Профили игроков, объединения, объявления, события, голосования и предложения.
- Личные и общие задачи с этапами, сроками, комментариями и ресурсами.
- Настраиваемые HUD, уведомления, темы интерфейса и библиотека скинов.
- Каналы чата, оформление TAB и имён игроков, навигация по координатам.
- Серверные инструменты модерации, авторизации и диагностики.

Интеграции с LuckPerms, Plasmo Voice, Xaero’s, Create: Access Denied и spark
подключаются автоматически при наличии совместимого мода.
Менеджер сборок работает самостоятельно на клиенте; серверные функции требуют
установки Rivet на сервере.

## Требования

| Компонент | Версия |
| --- | --- |
| Minecraft | 1.21.1 |
| Java | 21 |
| NeoForge | От 21.1.250 в ветке 21.1 |
| PostgreSQL | Обязательна для серверной части |

Конкретную версию NeoForge для клиентской сборки задаёт её владелец.

## Установка

**Игрокам:** скачайте JAR из [релиза](https://github.com/abrosdaniel/rivet/releases/latest)
и поместите в `mods/` клиента. На сервере откройте меню клавишей **F8** или командой `/rivet`.
Подробности — в [руководстве игрока](docs/player-guide.md).

**Владельцам серверов:** поместите JAR в `mods/` сервера и настройте PostgreSQL
в `config/rivet-server.toml`. Установка, конфигурация и права описаны
в [серверном справочнике](SERVER_GUIDE.md).
