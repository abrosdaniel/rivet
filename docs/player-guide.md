# Начать играть

Установите Rivet в `mods/` клиента Minecraft **1.21.1** с **Java 21** и стабильным **NeoForge 21.1 от 21.1.250**.

[Скачать Rivet](https://github.com/abrosdaniel/rivet/releases/latest){ .rivet-button .rivet-button-primary }

1. Добавьте сервер в сетевой игре и подключитесь.
2. Если сервер предлагает сборку, выберите компоненты и подтвердите установку. После применения файлов перезапустите игру.
3. Откройте меню сервера клавишей **F8**, карту — **M**, выбор скина — **F7**.

Доступные функции определяет сервер. Клавиши можно изменить в управлении Minecraft.
