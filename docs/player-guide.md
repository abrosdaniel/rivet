# Руководство игрока

Rivet устанавливается в папку `mods/` клиента Minecraft 1.21.1 с NeoForge от 21.1.250 в ветке 21.1 и Java 21.
Скачать мод можно на [странице релизов](https://github.com/abrosdaniel/rivet/releases/latest).

## Управление

На сервере меню открывается **F8** или командой `/rivet`.
Для быстрой смены скина можно назначить клавишу в управлении Minecraft.
Клавиши переназначаются в управлении Minecraft. **Esc** закрывает меню,
**Backspace** закрывает основной раздел или возвращает из вложенного окна;
в поле ввода удаляет символы.

Начальный масштаб GUI — 3. Изменённый игроком масштаб сохраняется.
Виджет включён по умолчанию; его расположение, содержимое и видимость настраиваются.
Клиентские настройки общие для всех серверов.

## Установка клиентской сборки

При подключении Rivet получает сведения о сборке от самого сервера. При первом
подключении подтвердите ключ сервера. Если ключ изменился, уточните его у владельца
перед подтверждением. Затем выберите необязательные компоненты, просмотрите список
добавлений, замен и удалений и подтвердите установку.

Необязательные компоненты выбираются галочками. Обязательные файлы тоже
показаны в списке: они отмечены, отключить их нельзя. Описание компонента
или полный путь файла доступны при наведении.

Моды по ссылкам сначала скачиваются с Modrinth или CurseForge. Если источник
недоступен или файл не прошёл проверку, Rivet автоматически загружает копию
с сервера. Локальные файлы загружаются с сервера.

После загрузки закройте Minecraft кнопкой в окне Rivet, дождитесь применения файлов
и снова запустите игру своим лаунчером. При повторном подключении Rivet проверит
сборку; уже установленное повторно скачивать не нужно. Выбор необязательных
компонентов сохраняется отдельно для каждого сервера. Minecraft, NeoForge и Rivet
устанавливаются отдельно — окно сообщает, если нужны другие версии.

В списке сетевой игры выберите сервер и нажмите **Сборка** рядом с кнопкой
подключения. Здесь можно изменить компоненты до входа на сервер. Перед применением
показывается обзор изменений. Если файлы не меняются, перезапуск не нужен.
Если обновление уже подготовлено, сначала завершите его.

При переходе на другой сервер Rivet предлагает заменить файлы прежней сборки.
Настройки конфигов, установленных сборкой, сохраняются отдельно для каждого сервера
и восстанавливаются при возвращении. Личные конфиги, существовавшие до установки,
остаются общими. Изменение набора файлов требует закрытия и повторного запуска игры;
при совпадающих файлах можно подключаться сразу.

Личные конфиги по умолчанию сохраняются; конкретные замены задаёт владелец сервера
и показывает обзор изменений. Перед заменой или удалением файлов создаётся
резервная копия. Дополнительные клиентские моды можно оставить: Rivet удаляет только
файлы, которыми управляла установленная сборка. Изменённые управляемые файлы
отмечаются в обзоре, чтобы вы могли отменить установку до их замены или удаления.
Если личный мод дублирует мод сборки под другим именем файла, установка остановится
и перечислит конфликтующие файлы. Удалите личный дубликат вручную и повторите
проверку; Rivet не удаляет его автоматически.

Неиспользуемые файлы загрузок старше семи дней удаляются из кэша при запуске.
Активные файлы, незавершённые установки, резервные копии и сохранённые настройки
сборок серверов сохраняются.

При смене сборки и выборе компонентов Rivet проверяет зависимости и конфликты
итогового набора модов, включая личные моды и вложенные библиотеки. Если новая
сборка удаляет или заменяет необходимую личному моду библиотеку, установка
останавливается до изменения игровых файлов. Измените выбор компонентов или
состав личных модов и повторите проверку.

## Меню сервера

| Раздел            | Назначение                                                         |
| :---------------- | :----------------------------------------------------------------- |
| Главная           | Сводка, закреплённое объявление, ближайшие события и задачи        |
| Игроки            | Поиск игроков, профили, статистика и последняя активность          |
| Мои задачи        | Личные задачи; задачи объединения доступны внутри объединения      |
| Доска объявлений  | Публикации, покупка, продажа и обмен                               |
| Объединения       | Участники, заявки, общие задачи и места                            |
| События           | Встречи, запись, очередь участников и напоминания                  |
| Голосования       | Решения сообщества и разрешённые сервером голосования о нарушениях |
| Предложения       | Идеи игроков и обсуждение                                          |
| Помощь            | Текст помощи и ссылки владельца сервера                            |
| Администрирование | Сводка и инструменты для игроков с соответствующими правами        |

Доступные разделы определяет сервер. Уведомления открываются из шапки меню. Личные сообщения используют чат Minecraft; отдельного мессенджера Rivet нет.

### Ресурсы и склады задач

Для задачи можно указать предметы и требуемое количество, затем привязать контейнер табличкой с тремя строками:

```text
&rivet
Название объединения или ник владельца личной задачи
Код задачи, например 7K2P
```

Код задачи остаётся прежним при переименовании. Привязку выполняет владелец личной задачи или управляющий объединения. Rivet учитывает содержимое загруженных контейнеров; для выгруженных показывает последнее подтверждённое состояние и время проверки, без дополнительной прогрузки чанков.

## Чат

В настройках Rivet → Чат можно выбрать объём истории: 100, 1 000 (по умолчанию), 10 000 или
65 536 сообщений. Она доступна при прокрутке открытого чата;
локальная история текущего подключения не является архивом на диске.

При входе сервер подгружает прошлые сообщения ниже новых: общий канал,
сообщения доступных вам объединений и локальные сообщения, полученные вами
ранее рядом с отправителем. После выхода из объединения его история больше
не подгружается. По умолчанию сервер выдаёт до 100 сообщений, хранящихся не
дольше семи дней; владелец сервера может изменить эти значения или отключить
синхронизацию. Сообщения истории не выдаются за заново подписанные сообщения
игроков.

Если сервер использует чат Rivet, сообщения пишутся в обычной строке чата Minecraft:

| Ввод                | Кому отправится сообщение                                  |
| :------------------ | :--------------------------------------------------------- |
| `привет`            | Игрокам рядом; если локальный канал выключен — в общий чат |
| `!привет`           | В общий чат                                                |
| `#Название: привет` | Участникам указанного объединения                          |

При вводе `#` появляется стандартный список подсказок Minecraft с доступными объединениями: ↑↓ выбирают, Tab вставляет название. Если вы состоите только в одном объединении, можно написать `#привет`.

`[pos]` вставляет ваши координаты: получатель может нажать на них и начать маршрут. Доступность каналов и координат определяет сервер.

Стандартный формат сообщения: **[канал] | голова префикс ник суффикс: текст**. Метка общего чата по умолчанию скрыта; у локального указано «Рядом», у объединения — его название. Префикс и суффикс приходят из LuckPerms, если он установлен на сервере. Сервер может задать собственный формат сообщений.

Подсказку по вводу можно отключить и настроить в **Настройки Rivet → Чат**. Сервер включает или выключает чат Rivet целиком; отдельных режимов чата нет.

## TAB

TAB показывает список игроков с головами, метаданными LuckPerms и полосками качества связи. В **Настройки Rivet → TAB** доступны группировка по алфавиту, ролям или объединениям, головы, точный пинг, прозрачность, плотность строк и ширина колонок. Точный пинг по умолчанию выключен.

Сервер определяет, использовать оформление Rivet или стандартный TAB, и может разрешить автоматический выбор с учётом других модов. Игрок настраивает внешний вид доступного списка.

Для взаимодействия с TAB и виджетом назначьте клавишу **«Режим курсора»** в управлении Minecraft. Нажмите её при открытом TAB, чтобы выбрать игрока мышью. Повторное нажатие или Esc возвращает управление игрой. Большие списки прокручиваются колесом.

## Настройки и навигация

**Настройки** находятся внизу основного меню Rivet. Окно объединяет общие параметры, оформление, виджет, уведомления, TAB и чат. В общих параметрах доступны часовой пояс, голограммы складов и виджеты главной. Настройки карты, миникарты и навигации открываются шестерёнкой на большой карте. Есть поиск параметров, светлые и цветные темы, предпросмотр. Настройки сохраняются автоматически; сброс затрагивает только выбранный раздел.

- Виджет можно отключить, выбрать его содержимое и переставить блоки перетаскиванием. Время сессии по умолчанию выключено.
- Общие кнопки «Клавиши…» и «Редактор HUD…» открывают назначение клавиш и размещение HUD. В компактном окне они находятся в меню разделов. Масштаб интерфейса и параметры текста/фона чата настраиваются в Minecraft.
- Редактор HUD перемещает миникарту, виджет, подсказку чата и указатель маршрута; колесо меняет размер, R восстанавливает расположение, Esc завершает редактирование. Сброс настроек виджета сохраняет его размер и положение.
- Кнопка «Скины» открывает библиотеку. F7 используется для быстрой смены сохранённого скина.
- Координаты из чата и «Идти сюда» в карточке места создают один временный маршрут. Новый заменяет предыдущий; маршрут остаётся активным до прибытия или ручной остановки, без ограничения по времени. Он виден и при открытом чате. Чтобы остановить его, нажмите × на указателе в чате или режиме курсора.
- Маршрут отображается на карте и миникарте Rivet. Его метку можно скрыть в настройках навигации; сохранённые личные точки не изменяются.
- Общие места и добровольно передаваемые позиции участников отображаются на карте и миникарте Rivet. Устаревшие позиции исчезают автоматически. Через меню точки можно начать маршрут или открыть создание личной метки; само отображение ничего не сохраняет в личные метки.
- Голограмма привязанного хранилища показывает информацию вблизи, когда хранилище видно.

## Интеграции

Rivet автоматически подключает поддерживаемые установленные моды:

| Мод                         | Возможности                                                |
| :-------------------------- | :--------------------------------------------------------- |
| LuckPerms                   | Права, префиксы и суффиксы игроков                         |
| Plasmo Voice                | Голосовая модерация и диагностика подключения              |
| Simple Voice Chat           | Голосовая модерация и диагностика подключения              |
| Waystones                   | Доступные игроку камни на карте и миникарте                  |
| Create: Access Denied       | Совместимость списков доступа с аккаунтами Rivet           |
| spark                       | Диагностика производительности для администрации           |

Камни Waystones появляются автоматически: открытые игроком, общедоступные и доступные его команде. Смена видимости, названия и удаление отражаются на карте при следующем обновлении (обычно до двух секунд). Иконка использует модель и текстуры предмета Waystones с учётом ресурспака. Нажатие позволяет начать маршрут; активация и телепортация остаются в Waystones. Камни не копируются в личные метки.

Эти моды устанавливаются отдельно. Для передачи своей позиции участникам объединения нужно согласие игрока; история позиций не сохраняется. Настройка и диагностика интеграций описаны в [серверном справочнике](../SERVER_GUIDE.md#необязательные-интеграции).

## Обновление клиента

Кнопка с иконкой Rivet справа от «Сетевой игры» открывает окно обновлений.
Версия Rivet также отображается слева внизу рядом с версиями Minecraft и NeoForge.
Подсказка показывает установленную версию. При обновлении кнопка получает
плавно пульсирующую золотую рамку, а подсказка — строку с доступной версией.
При отключённых анимациях рамка остаётся постоянной.
После установки перезапустите игру.
Список версий сохраняется между запусками: повторные запросы выполняются
не чаще раза в 15 минут. При недоступности GitHub используется сохранённый
список не старше недели, а следующая попытка возможна через 5 минут.

Серверы встроенного каталога отображаются в обычном списке серверов Minecraft.
Каталог обновляется вместе с Rivet; его серверы нельзя удалить или изменить
через список. Свои серверы можно добавлять и редактировать как обычно.
Требуемые версии мода и компонентов сборки задаёт сервер.

Клиент Rivet должен быть не старее серверного в той же основной ветке.
Например, сервер 2.0.0 принимает клиент 2.0.0 или 2.1.0 при совместимых сетевых
протоколах; клиент 1.x не подходит.
После отказа подключения кнопка выбора версии предлагает выпуски не ниже серверного.

## Карта мира

**M** открывает карту; клавишу можно изменить в настройках управления Minecraft.
Перетаскивание перемещает карту, колесо масштабирует её под курсором.
Карта занимает всё окно; инструменты и список меток располагаются поверх неё.
Карта запоминает поверхность чанков, уже полученных клиентом от сервера. Цвета учитывают текстуры блоков, биомы и рельеф; вода и прозрачные блоки сохраняют видимость поверхности под ними. Новые чанки ради карты не запрашиваются.
Правая кнопка открывает контекстное меню: создание и изменение меток, навигация,
копирование координат и удаление с подтверждением. Телепортация доступна, только
если сервер разрешает игроку соответствующую команду. Двойной щелчок создаёт метку.
Инструменты слева: остановка активного маршрута, возврат к игроку, создание метки,
список меток, приближение, отдаление, слои, территории и линейка. Без активного маршрута кнопка остановки
скрыта. Экспорт доступен в контекстном меню по правой кнопке.
Названия инструментов видны при наведении.
Линейка измеряет расстояние между двумя щелчками по карте. Перетаскивание и масштаб
не меняют измерение; подпись вдоль линии показывает число блоков; правая кнопка очищает измерение, Esc выключает линейку.
Телепортация использует стандартную команду сервера. Высота берётся над верхним
слоем карты, включая воду, с дополнительным отступом в полблока. Метка использует
сохранённую высоту; изменение местности после её создания может сделать её неактуальной.


Метки сохраняют размер при масштабировании и имеют контрастную подложку и подпись.
Щелчок по метке открывает карточку справа. Название и палитра цветных квадратов закреплены в панели. Отдельная область выбора из 103 значков прокручивается. Поле названия новой метки изначально пустое. Новая метка получает случайный цвет рамки и создаётся без значка. Внутри рамки показана крупная первая буква названия; пока название пустое, рамка остаётся пустой. Первый вариант в выборе — «Без иконки». Цвет и значок можно изменить перед сохранением.
Новая метка сразу видна на карте. Изменение названия, значка и цвета сразу отражается на ней.
Чтобы изменить позицию, перетащите метку левой кнопкой мыши. Координаты в карточке
обновляются; на исследованной поверхности высота берётся из карты.
Сохранение применяет изменения, отмена восстанавливает прежние значения.
Esc во время переноса или отпускание над панелью отменяет перенос.
Навигация, удаление и доступная телепортация имеют подписанные действия. Название измерения
сверху открывает список измерений. При открытии карты выбрано измерение игрока.
Начало навигации закрывает карту; остановить её можно в карте или крестиком HUD.

### Слои и территории

Кнопка «Слои» на панели карты задаёт общую видимость для большой карты и
миникарты: один переключатель включает или скрывает слой на обеих. В окне доступны личные метки, территории, места смерти, общие места,
Waystones, задачи, события, игроки, существа и цель маршрута.
Фильтр «Игроки» управляет отображением, а передача вашей позиции настраивается отдельно. Доступ к
серверным точкам и радару определяется сервером; скрытие слоя не удаляет данные.

Слои «Задачи» и «События» доступны при поддержке сервером соответствующих модулей.
В обзоре задачи можно добавить, изменить или убрать **место назначения**. Оно
необязательно: задача без места работает как обычно и не появляется на карте.
Привязанный склад не становится местом назначения автоматически.

На карте отображаются открытые задачи и задачи в работе, а также события,
которые ещё не закончились. Нажатие на точку открывает действия «Идти сюда» и
переход в карточку задачи или события. Из карточки задачи место можно показать
на карте. Доступ определяется правами на исходную запись и её место.
Данные обновляются автоматически; отменённые события, завершённые/архивные задачи
и недоступные точки исчезают. При изменении места активный маршрут следует за
ним, при удалении точки останавливается. Эти точки не сохраняются в личных метках.

Кнопка «Территории» открывает территории объединений. У каждого объединения
одна территория вместо одиночной координаты. Руководитель, помощники и
администрация могут создать или изменить её из карточки объединения либо
из списка на карте. Выберите своё объединение,
расставьте минимум три вершины левой кнопкой мыши и замкните контур нажатием
на первую точку. Она выделяется рамкой после добавления третьей вершины.
Точки привязываются к границам блоков. Перетаскивание перемещает карту,
колесо меняет масштаб; правая кнопка и Backspace убирают последнюю точку, Esc отменяет
черновик. Название территории всегда совпадает с названием объединения и меняется
вместе с ним. Отдельного имени у территории нет. В форме можно выбрать цвет из сетки квадратов,
как у меток, изменить координаты X/Z,
удалить вершины или начертить границу заново. Изменения применяются по «Сохранить».

Территории имеют заливку, границу и название на большой карте; миникарта показывает
их контуры и заливку с учётом поворота и своей формы. Для изменения откройте
территорию из списка или контекстного меню внутри области. Удаление требует
подтверждения. Допустимы вогнутые контуры и пересечения разных территорий;
самопересечения одного контура запрещены. Каждый контур содержит 3–128 вершин.
Территории видны всем и хранятся на сервере; защиты блоков они не дают.

Вкладка «Метки» в объединении содержит его внутренние места. Они доступны
участникам и администрации; руководитель и помощники управляют этим набором.
Слой «Метки объединений» показывает их на большой карте и миникарте. При выходе
из объединения доступ к этим точкам прекращается. Отключение модуля объединений
убирает территории, внутренние метки и позиции участников из обеих карт,
скрывает их инструменты и слои и прекращает запросы этих данных. Личные метки
и личные задачи не зависят от модуля объединений.

### Настройки карты и радар

Шестерёнка в левом нижнем углу карты открывает единое окно с разделами «Отрисовка»,
«Миникарта», «Метки», «Навигация», «Радар» и «Пещерная карта». Настройки сохраняются автоматически;
сброс затрагивает только выбранный раздел. Поиск в общих настройках также находит
параметры карты и открывает нужный раздел.

Можно включать освещение и затенение по высоте, выбирать затенение склонов,
показывать биом под курсором, менять размер меток и минимальный масштаб их показа.
Цвета, свет и прозрачность исследуемых слоёв сохраняются отдельно, поэтому свет
пересчитывается и на сохранённой местности. Старые данные без отдельных прозрачных
слоёв и названий биомов дополняются при повторном получении чанков клиентом.

Радар показывает полученные клиентом сущности на большой карте и миникарте.
Игроки и существа включаются в «Слоях». Фильтры враждебных и дружелюбных существ
находятся в разделе «Радар» настроек.
Выпавшие предметы и прочие объекты не показываются. Доступны иконки или точки, имена и фильтр по разнице высот.
Иконки показывают головы мобов из текущих текстур и моделей; у существ без
отдельной головы — лицевую часть. Игроки отображаются лицом своего скина с
верхним слоем. Если нестандартная модель другого мода не поддерживается,
остаётся цветная точка. Яйца призыва вместо существ не используются. Невидимые сущности
и игроки-наблюдатели не показываются. Сервер может отключить радар.

### Экспорт карты

Кнопка экспорта на левой панели открывает сохранение видимой области в PNG.
Экспортируется местность текущего измерения и слоя с выбранным освещением,
без интерфейса, меток и радара. Неизвестные участки остаются прозрачными;
новые чанки не запрашиваются. При большой области изображение уменьшается
до 4096 пикселей по каждой стороне. Файл сохраняется в `rivet/exports`
в папке игры; экспорт продолжается после закрытия окна.

В разделе «Отрисовка» настраиваются общие цвета и рельеф обеих карт. По умолчанию
используются точные цвета текстур с учётом биомов, освещение, затенение по высоте
и направленное затенение склонов. Ночь и погода меняют освещение автоматически;
светящиеся блоки и освещённые участки сохраняют свой свет. Выключение «Освещения»
позволяет смотреть карту при полной яркости. Экспорт PNG учитывает текущий свет.

Можно выбрать стандартные цвета карты Minecraft, включить для них цвета биомов,
настроить смешивание цветов биомов, показ цветов, редстоуна и цветного стекла,
прозрачность блоков и поправку высоты тонких блоков. Все эти параметры, кроме
цветов биомов в режиме Minecraft, изначально включены. Изменения способа выборки
поверхности обновляют полученные клиентом чанки; удалённые сохранённые участки
уточняются после повторного посещения. Старые карты без отдельных данных света
также уточняются при посещении.

Новая миникарта квадратная, непрозрачная, с масштабом 1×; форму, прозрачность
и масштаб можно изменить. Ранее сохранённые пользовательские значения сохраняются.

### Пещерная карта

Настройки пещер открываются через шестерёнку на карте → «Пещерная карта». Типы: «Выкл.», «По слоям» и «Вся глубина».

- Верхний Y задаётся числом и применяется сразу. `Auto` или пустое поле возвращает
  автоматический выбор. Недопустимая высота не меняет последний верный срез.
- Автоматика большой карты по умолчанию следует миникарте. Можно отключить её
  или выбрать потолок 1×1, 3×3, 5×5; у миникарты есть собственный выбор потолка.
  Начальное значение миникарты — 3×3. Листва, жидкости и прозрачные блоки не
  считаются потолком; открытый небесный свет препятствует включению пещер.
- Задержки большой карты и миникарты настраиваются отдельно от 0 до 10 секунд
  с шагом 0,1 секунды. По умолчанию между переключениями проходит не менее
  секунды; первое включение и отслеживание высоты внутри пещеры не задерживаются.
- «По слоям» хранит карту в диапазонах по 16 блоков. Верхний Y определяет срез
  внутри диапазона; глубина от 1 до 64 включает сам верхний блок. Начальная
  глубина — 30. Поиск пола начинается после воздуха или жидкости под потолком.
- «Вся глубина» проходит под грунт и показывает первый открытый пол под ним,
  без ограничения глубины. Ручной Y и глубина среза для этого типа не применяются.
- «Освещение по глубине» выключено по умолчанию. При включении яркость зависит
  от высоты пола относительно выбранного среза. Пустой исследованный столбец
  отображается тёмным, а не как неисследованный участок.
- Пещерный масштаб миникарты — от 1× до 4×, начальное значение 2×.
  Показ верхнего Y можно отключить. Клавиша ручного пещерного режима миникарты
  назначается в управлении; она использует заданный Y или высоту над игроком
  при автоматическом Y.

Поверхность и пещерные слои сохраняются отдельно. Карта использует только чанки,
уже полученные клиентом. Выбор среза запоминается для мира и измерения;
параметры автоматики, задержек и масштаба общие. Существующие пользовательские
значения сохраняются. Новые метки используют высоту выбранного слоя.
Сервер может запретить пещерную карту.

### Точки смерти

После смерти карта создаёт личную тёмно-серую метку с датой и измерением.
Её цвет фиксирован; на полной карте вместо названия показан обратный отсчёт. Она удаляется
через 10 минут с момента смерти, включая время вне игры, или раньше при прибытии
живого игрока: не дальше 3 блоков по горизонтали и 4 по высоте в том же измерении.
Обычные метки остаются на месте. Маршрут к удалённой точке смерти завершается.

Точки смерти нельзя редактировать или перемещать; череп используется только для них.
Нажатие открывает меню действий: маршрут, копирование координат, удаление и
телепортация при наличии прав. Подсказка показывает дату смерти один раз.

В фильтре списка выберите **Точки смерти**, чтобы увидеть оставшиеся точки,
начиная с последней. Их можно удалить вручную. В настройках карты можно отдельно
скрыть точки смерти на карте и миникарте; это не продлевает время их хранения.

### Категории и видимость меток

В панели меток поиск работает при вводе и учитывает название метки и категории.
Фильтр категории оставляет нужные записи в списке. Скрытые метки доступны для редактирования.

В карточке можно ввести координаты, выбрать категорию и отдельно включить показ
на карте и миникарте. В небольших окнах эти поля находятся в окне
«Координаты и видимость». Изменения метки применяются кнопкой «Сохранить».

Кнопка управления категориями находится рядом с выбором категории. Категория
имеет название и собственную видимость на каждой карте. Для показа должны быть
включены оба переключателя: метки и её категории. Удаление категории сохраняет
метки без категории. Категории хранятся отдельно для каждого мира и игрока.
Точки смерти используют свои настройки отображения и не входят в категории.

### Импорт личных меток

Откройте **Шестерёнка на карте → Метки → Импорт меток**. Поддерживаются актуальные
TXT-файлы Xaero’s Minimap и `WaypointData.dat` JourneyMap. Устанавливать эти моды
для переноса не требуется. Можно выбрать несколько файлов, папку меток одного
мира или перетащить файлы в окно. Вложенные папки не сканируются.

В предпросмотре проверьте названия, координаты, цвета и измерения. Для TXT
выберите измерение вручную: оно не записано внутри файла. При необходимости
поменяйте измерение из DAT. Координаты переносятся без пересчёта между мирами.
Снимите галочки с ненужных меток и нажмите «Импортировать». Метки с одинаковыми
именем, измерением и координатами пропускаются; существующие метки не изменяются.
Скрытые метки остаются скрытыми. Точки смерти, временные метки и записи без
высоты пропускаются с объяснением в списке. Внешние значки заменяются значком
метки Rivet. Категории и права внешних модов не переносятся.

Импорт сохраняет только личные метки текущего мира и игрока. Перед записью
существующий файл меток копируется в `backups` рядом с `markers.json` в локальном
хранилище карты. Исходные файлы не меняются. Ограничения: 4096 личных меток,
2 МБ на файл и 16 МБ за одну операцию. Старый JSON JourneyMap не поддерживается.

### Миникарта

Миникарта показывает тот же выбранный слой поверхности или пещер и личные метки.
Обозначения сторон света соответствуют языку игры: С, Ю, З, В для русского. Она остаётся
видимой при открытом чате. Удержание Z увеличивает её; клавишу можно переназначить
в настройках управления Minecraft.

По умолчанию миникарта поворачивается по взгляду; сохранённые настройки игрока сохраняются.
В **Шестерёнка на карте → Миникарта** можно отключить миникарту, выбрать круглую или
квадратную форму, север сверху или поворот по взгляду, масштаб местности и
прозрачность. Координаты, биом, время мира и погода включаются отдельно.

В редакторе HUD колесо над элементом меняет его размер: миникарта, виджет,
подсказки чата, указатель маршрута и плашки уведомлений настраиваются отдельно.
Миникарту, виджет, подсказки и указатель можно перетаскивать. Общий масштаб GUI
выбирается в настройках Minecraft.
Размещение сохраняется при смене разрешения. В режиме курсора Rivet колесо
меняет масштаб, а щелчок по метке открывает её карточку на большой карте.
Метки за пределами миникарты немного выступают за её край в направлении своей позиции
и открывают карточку при нажатии на выступающую часть. При ускорении миникарта
плавно отдаляется, при замедлении возвращается к выбранному масштабу.
Под картой по центру отображается строка `Мир · 0, 0, 0`
с текущим измерением: Мир, Ад или Энд.
Отключение модуля карты сервером отключает и миникарту.

Исследованная поверхность и метки сохраняются отдельно для мира и игрока.
Карта исследует надземную поверхность, в том числе под листвой. Закрытые пещеры и измерения
с потолком этим режимом не раскрываются. Карта доступна, если сервер разрешает её.


### Видимость позиции игрока

В настройках карты выберите раздел «Видимость». Режим и аудитория доступны
прямо в этом разделе. По умолчанию позиция видна
**на всей карте всем игрокам**. Можно выбрать «Только рядом» или «Скрыто»;
аудитории — все игроки, участники ваших объединений или никто. Нажмите
«Сохранить», чтобы применить выбор. Он сохраняется на этом сервере.

«Только рядом» означает расстояние до 128 блоков в том же измерении, включая
разницу высот; владелец сервера может изменить радиус. Правила общие для большой
карты и миникарты. Сервер передаёт только разрешённые координаты. Скрытие убирает
голову игрока и останавливает маршрут к нему; позиции не сохраняются в историю
карты или личные метки. При потере связи устаревшие позиции исчезают.

Аудитория объединений учитывает текущее членство. При отключённом модуле
«Объединения» эта аудитория никому не открывает позицию; аудитория «Все игроки»
продолжает работать.
