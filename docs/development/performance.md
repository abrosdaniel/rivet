# Измерение производительности

`PerformanceMetrics` сохраняет до 64 имён операций: количество, суммарное и
максимальное время, число ошибок. Записи не содержат идентификаторов игроков,
координат или содержимого запросов. Снимки неизменяемы.

Подробный режим `PerformanceMetrics.detailed(true)` дополнительно хранит последние
2048 измерений каждой операции. `distributions()` возвращает p50/p95/p99 по этому
окну методом nearest rank. Среднее и максимум из `snapshot()` относятся ко всем
записям после `clear()`, а не только к окну. `detailed(false)` освобождает окна.
Замеры частых клиентских путей выключены по умолчанию: `start()` возвращает 0,
не обращаясь к часам; `end()` ничего не записывает.

Измерены отдельными операциями сканирование карты, отрисовка миникарты,
подготовка/отрисовка меток и отрисовка большой карты. Время вложенных операций
нельзя складывать: оно уже входит во время вызывающей операции. Это время CPU
и подачи команд рендеру, не прямое измерение GPU. Большая карта отдельно измеряет поверхность,
подготовку занятых областей, метки и проверки пересечений. Для проверок
пересечений число вызовов отличается от числа кадров: среднее время на кадр
считается как суммарное время проверок, делённое на число отрисовок карты. `database.acquire` отражает
успешное получение соединения в подробном режиме; существующая
`database.transaction` включает полную транзакцию и её ошибки.
`map.positions.policies` и `map.positions.groups` измеряют запросы политик
видимости и членства; второй выполняется только для видимых кандидатов с
аудиторией объединений. Эти операции не включают остальные SQL обработчика.
