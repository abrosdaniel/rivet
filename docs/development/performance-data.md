# Большие наборы данных

SQL-проверки измеряют списки, карточки объединений и смешанную нагрузку до
100 игроков. Они не заменяют замеры игрового потока, сети и отрисовки клиента.

Используйте только изолированную PostgreSQL с переменными подключения
`TestDatabase`: тесты очищают её таблицы. Время запросов выводится как результат
замера, без зависимых от оборудования порогов успешности.

## Большие списки

`CommunityLargeReadTest` создаёт 6000 документов и 96000 связей. Часть документов
принадлежит удалённым механикам: тест проверяет, что они не попадают в выдачу.
Измеряются списки объединений с поиском редкого названия и без него. После
предварительного запроса выполняются пять измерений; JSON содержит медиану,
максимум и контрольную сумму страницы.

```sh
RIVET_LARGE_READ=true RIVET_LARGE_READ_OUTPUT=/tmp/large-read.json \
  ./gradlew :core:postgresTest --tests '*CommunityLargeReadTest' --rerun-tasks
```

Маркер завершения: `RIVET_LARGE_READ_OK`. SQL сначала отбирает не более
11 документов, затем восстанавливает состав участников только для этой страницы.
Главная использует собственные проекции; архивные события и доска не читаются.

## Карточка объединения

`GroupDetailLoadTest` создаёт объединение со 101 участником, 200 внутренними
метками и 200 архивными задачами. Первую, десятую и сороковую страницы он читает
по девять раз после предварительного запроса. Проверяются неизменность ответа,
лимит участников и меток на странице, отсутствие архивных задач в выдаче.

```sh
RIVET_GROUP_DETAIL_LOAD=true RIVET_GROUP_DETAIL_LOAD_OUTPUT=/tmp/group-detail.json \
  ./gradlew :core:postgresTest --tests '*GroupDetailLoadTest' --rerun-tasks
```

Маркер завершения: `RIVET_GROUP_DETAIL_LOAD_OK`. Отчёт содержит медиану,
максимум и размер JSON для каждой страницы.

## Смешанная нагрузка

`MixedModuleLoadTest` выполняет чтение и изменение объединений, чтение приватных
меток, запись и воспроизведение чата, загрузку уведомлений. Каждый игрок имеет
своё объединение и личную аудиторию локального чата. Тест проверяет изоляцию
данных, ограничения размера ответов и локализацию RU/EN.

```sh
RIVET_MIXED_LOAD=true RIVET_MIXED_PLAYERS=100 \
  ./gradlew :core:postgresTest --tests '*MixedModuleLoadTest' --rerun-tasks
```

Допустимо 1–100 игроков, по 240 операций на каждого, восемь рабочих потоков.
`RIVET_MIXED_SAMPLE` сообщает p50, p95 и максимум по типу операции.
`RIVET_MIXED_LOAD_OK` подтверждает завершение всех операций и проверок.
