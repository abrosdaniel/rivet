# Rivet UI Kit

Единая система интерфейса для всех экранов Rivet. Компоненты реализованы в
`rivet/mod/src/main/java/dev/abros/rivet/client`. Это руководство для разработки;
[руководство игрока](../player-guide.md) и [серверный справочник](../server/index.md) описывают использование мода.

## Основы

- Размеры задаются в GUI-пикселях, а не физических пикселях экрана.
- Отступы: 4, 8, 12, 16. Высота действия: 20; строки настройки: 24.
- Плоские поверхности. Без декоративных заклёпок, фасок и текстур под текстом.
- Один цвет акцента темы обозначает выбор и основные действия.
- Красный — ошибка или опасное действие; семантика не зависит от темы.
- Текст Minecraft рисуется без дробного масштабирования. Логотип сохраняет
  отдельные пропорции: знак 14 GUI-пикселей, название в обычном масштабе текста;
  имена игроков сохраняют оформление LuckPerms.
- Подпись, вторичный текст и состояние имеют разные роли. Не повторять один
  показатель в заголовке и содержимом.

## Токены и компоненты

| Элемент | Общий компонент | Правило |
| --- | --- | --- |
| Цвета и отступы | `UiKit` | Использовать семантические Surface, accent, text, muted, border |
| Тема | `UiPalette` | Одинаковая структура всех тем, цвета данных не заменять |
| Сокращение текста | `UiKit.fit` | Для форматированного текста передавать `Component`: цвета, стили и действия сохраняются |
| Действия | `UiActions` / `UiTheme` | NORMAL, PRIMARY, DANGER; один главный CTA в группе |
| Контекстное меню | `UiContextPopup` | Привязка к курсору, ограничение краями окна, прокрутка, Esc и закрытие кликом снаружи |
| Значки карты | `MapGlyphs` | Цветной PNG-атлас 16×16; собственные цвета спрайтов, цвет метки задаёт рамку |
| Цвет | `UiColorSwatch` | Цветной квадрат, отметка выбора, фокус и доступное название |
| Инструмент с иконкой | `UiActions.tool` | Название в Tooltip и narration; общий фокус, недоступное состояние и семантический цвет |
| Поля | `UiFields` | Нативное редактирование, выделение, подсказки и валидация |
| Настройка-выбор | `UiActions` | Подпись слева, значение справа, стрелка выбора |
| Переключатель | `UiToggle` | Вся строка кликабельна; состояние показано положением бегунка |
| Выбор | `UiChoiceRow` | Явная галочка, клавиатура и narration |
| Навигация | `SidebarButton`, `UiTabs` | Выбор отличается от недоступности |
| Меню выбора | `ChoicePopup`, `UiMenuItem` | Привязать к исходному контролу, сохранить контекст |
| Списки | `CommunityCard`, `PlayerRow` | Краткая запись, подробности по выбору |
| Сводка | `UiSummaryCard`, `UiMetricCard` | Заголовок, значение, вторичные детали |
| Прогресс | `UiProgress` | Реальные байты и количество файлов; неопределённые этапы без процента |
| Состояния | `UiState` | Загрузка, пусто, фильтр, ошибка имеют разные объяснения |
| Прокрутка | `ScrollScreen`, `UiScrollbar`, `UiSettingsSidebar` | Собственный gutter; текст не перекрывает полосу |
| Рабочая область | `UiWorkspace`, `UiPage` | Общие слоты шапки, навигации, контента, действий |
| Диалог | `UiDialog` | Спокойная поверхность; границы только для отделения слоёв |
| Настройки | `UiSettingsShell` | Прямая смена разделов, без накопления диалогов; `module` использует ту же геометрию для настроек карты и поиска по модулю |

## Состояния и доступность

Наведение меняет поверхность. Клавиатурный фокус получает отчётливую рамку.
Выбор обозначается акцентом и положением/галочкой, а не только цветом.
Недоступные действия сохраняют читаемую подпись; причину задаёт Tooltip.
Обрезанные подписи должны иметь полную подсказку. Существующие настройки
прозрачности HUD и чата сохраняются; рабочие страницы используют читаемый фон.
Повышенная контрастность усиливает текст и разделители. Reduced motion
продолжает управлять общей анимацией наведения.

## Добавление экранов

1. Выбрать UiWorkspace / UiPage / UiDialog и использовать их слоты.
2. Собрать экран из компонентов таблицы. Не рисовать локальную кнопку или поле.
3. Подробности и редко используемые действия показывать после выбора записи.
4. Сохранять текстовые значения, клавиатурный фокус и прокрутку при обновлении.
5. Проверить GUI 1/2/3, длинные подписи, пустой список, ошибку, светлую тему
   и повышенную контрастность. Проверить отсутствие пересечений элементов.

## Живой каталог и проверки

`UiKitShowcaseScreen` в `src/uiHarness` — интерактивный каталог производственных компонентов:
действия, настройки, поля, ошибки, навигация и карточки. Переключение темы и
переключателей работает. Каталог предназначен для разработчика, не добавляет
служебные пункты в меню игроков.

Каталог включён в ApprovedUiHarness: полные сценарии для основной, светлой
и контрастной тем на GUI 1/2/3; остальные темы проверяются выборочно на GUI 3.
CI проверяет выполнение сценариев, границы элементов, контраст и взаимодействия
без создания PNG (`RIVET_UI_SCREENSHOTS=false`). При сбое сохраняются логи.
Полные сценарии запускаются в окне 1280×1024; адаптивная проверка меняет его размеры.
Для локального визуального просмотра скриншоты сохраняются по умолчанию;
`verify_ui_snapshots.py` с режимом `auto` проверяет точное количество и целостность PNG.
Режим `checks` проверяет успешное завершение сценариев без чтения PNG.
