# Каталог серверов

Встроенный список хранится в `rivet/mod/src/main/resources/rivet-servers.json`
и поставляется внутри JAR. Для каждого сервера задаются стабильный `id`,
отображаемое `name` и `address` в формате адреса Minecraft. Изменение адреса
или названия сохраняет прежний `id`.

Каталог синхронизируется с обычным списком Minecraft при открытии главного меню.
Новые записи добавляются в конец; обновляемые сохраняют место. Записи каталога
защищены от изменения и удаления через интерфейс. Личные записи не удаляются
и не перезаписываются; совпадение адреса не создаёт дубль. Удаление сервера из
поставляемого каталога убирает только неизменённую запись, созданную Rivet.

Сведения о созданных записях сохраняются в `rivet/server-catalog.json` внутри
папки игры. Каталог не требует сетевого запроса и обновляется вместе с Rivet.
