# Необязательные интеграции

LuckPerms, Plasmo Voice, Simple Voice Chat, Waystones, Create: Access Denied, Create: Numismatics и spark устанавливаются отдельно. Rivet обнаруживает их и подключает поддерживаемые возможности автоматически. Отдельных выключателей интеграций нет.

- **LuckPerms:** проверка прав, префиксы, суффиксы и основная группа с учётом текущего контекста игрока. Права групп можно менять через [администрирование Rivet](permissions.md#управление-из-игры) или LuckPerms. Отсутствие API не выдаёт дополнительные права.
- **Plasmo Voice:** голосовая модерация и диагностика подключения; для управления правами требуется LuckPerms.
- **Simple Voice Chat:** голосовая модерация через голосования Rivet и диагностика подключения, микрофона и звука.
- **Waystones:** отдельный слой доступных игроку обычных камней на карте Rivet. Список выбирается на сервере через правила Waystones: активированные, глобальные и командные точки. Неактивированные скрытые камни не передаются. Нет телепортации, открытия точек или сохранения копий в личные метки. Адаптер работает автоматически при совместимом API и включённом модуле карты; без Waystones карта работает самостоятельно. Sharestones и Warp Plates не входят в этот слой.
- **Create: Access Denied:** совместимость списков доступа с идентичностью аккаунтов Rivet, без изменения UUID Minecraft.
- **Create: Numismatics:** имена владельцев счетов и карт получаются через идентичность Rivet, включая зарегистрированных игроков офлайн. Пользовательские названия счетов сохраняются. Адаптер не меняет UUID, балансы и списки доступа; счета, созданные под другим UUID до подключения Auth, автоматически не переносятся. Для клиентских подписей Rivet нужен и на сервере, и на клиенте.
- **spark:** панель производительности, профилирование, отчёты и предупреждения о нагрузке. Для просмотра требуется `rivet.diagnostics`; для действий — также права spark `spark.profiler`, `spark.healthreport` или `spark.all`. Rivet останавливает и отменяет только запись, запущенную из своей панели. Отчёты загружает сам spark в свой просмотрщик.

Адаптеры подключены через провайдеры [Java API](../api/java.md#провайдеры-интеграций) и поставляются внутри одного JAR Rivet.

Состояние адаптеров доступно через `/rivet compatibility`; состояние клиентских интеграций — в технической сводке. Диагностика различает отсутствие мода, несовместимый API и временную ошибку. Три неожиданных сбоя отключают только соответствующий адаптер до перезапуска сервера или смены клиентского соединения.

Simple Voice Chat подключается через официальный API 2.5+ автоматически.
В диагностике голоса доступны подключение UDP, состояние микрофона и звука;
серверный мут Rivet отображается при подключении к серверу с адаптером.
Мут блокирует исходящий голос до его распределения в близкий, шёпотный или
групповой канал. Срок хранится по UUID в `rivet/voicechat-mutes.json` в папке
сервера и переживает переподключение и перезапуск. Включайте этот файл в
резервные копии. Просроченные записи не действуют и удаляются при следующей
записи. Аудиопакеты не обращаются к диску или БД. Собственные ограничения
других голосовых плагинов не снимаются.

Если установлены оба голосовых мода, для голосового голосования должны быть
доступны оба адаптера; наказание применяется к обоим. Существующий активный
мут не заменяется новым. Сбой одного API не считается успешным наказанием;
уже применённое ограничение другого адаптера автоматически не снимается.
Сам Simple Voice Chat и его сетевой порт настраиваются отдельно по
[документации мода](https://modrepo.de/minecraft/voicechat/wiki/server_setup).

История последних 30 отчётов spark сохраняется в папке мира `rivet/spark-reports.json`. Диагностика содержит графики за последние 15 минут. Предупреждения о нагрузке можно временно отключить для своего администратора до перезапуска сервера.

## Совместимость

Следующие версии проверены совместно на Minecraft 1.21.1 / NeoForge 21.1.250:

| Мод | Версия | Зависимость |
| --- | --- | --- |
| LuckPerms | 5.4.150 NeoForge | — |
| Plasmo Voice | 2.1.17 | — |
| Simple Voice Chat | 2.6.22 NeoForge | — |
| Waystones | 21.1.46 | Balm 21.0.66 |
| Create: Access Denied | 0.0.4+c6.0.10.mc1.21.1 | Create 6.0.10 |
| Create: Numismatics | 1.1.0 NeoForge | Create 6.0.10 |
| spark | 1.10.124 NeoForge | — |

LuckPerms нужен только на сервере. Остальные моды устанавливайте согласно их
требованиям к клиенту и серверу. Совместимость будущих версий зависит от сохранения
API; состояние конкретной установки проверяйте через `/rivet compatibility`.
