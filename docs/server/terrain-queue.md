# Очередь рендера

Обновление изменённых областей и восстановление заданий.

Планировщик принимает до 16 незавершённых заданий и исполняет их по очереди.
`GET /api/v1/map/terrain/jobs` с правом `map.render.manage` показывает до 32 последних
заданий, включая ожидающие (`QUEUED`), восстановленные и завершённые. Отменять можно
как активное, так и ожидающее задание. ID и подтверждённый прогресс сохраняются
в `rivet-terrain/schedule.json` внутри мира. Не удаляйте этот файл для остановки задачи:
используйте API отмены. Повреждённый журнал останавливает запуск функции с ошибкой.

Полный обход продолжится с последней подтверждённой позиции; незаконченный чанк
может быть обработан повторно. При изменении ресурсов/настроек незавершённые задания
пересчитываются для нового поколения. Изображения остаются атомарными файлами.

Изменения блоков автоматически попадают в общую очередь, включая команды и
обновления соседей. Повторы объединяются, а новые изменения во время рендера
не теряются. Очередь ограничена 4096 чанками; при переполнении запускается сверка
сохранённой области. После аварийного завершения она также закрывает интервал
между последним checkpoint и сбоем. Сверка читает сохранения, не загружает чанки
в игровой мир и не генерирует новые. Обычная остановка сохраняет очередь без
обязательного полного прохода при следующем запуске.
