# Включение функций

Настройте доступные модули и разделы меню.

В разделах `[groups]`, `[reports]`, `[server]` и `[trade]` параметр `enabled = false`
выключает функцию после полного перезапуска сервера. По умолчанию они включены.

| Раздел | Что выключается |
| --- | --- |
| `[trade]` | Создание и изменение предложений обмена. Возврат и получение уже сохранённых предметов остаются доступны. |
| `[groups]` | Объединения, роли, приглашения, общие метки, территории и канал объединений. |
| `[reports]` | Обращения, жалобы и действия модерации через Rivet. Команды Minecraft и других модов сохраняют свои права. |
| `[server]` | Объявления, закрепление, обслуживание и запланированная остановка. Просмотр конфигурации и диагностика остаются доступны администрации. |

Выключение не удаляет записи. Старые ссылки не обходят ограничения сервера.
Задачи, склады, события, доска, опросы сообщества и предложения больше не
запускаются; старые настройки не включают их повторно. Их сохранённые данные
доступны через [архивный экспорт](maintenance.md).

`community.sections` управляет составом меню. Выключатель функции действует
независимо от этого списка: добавление раздела в меню не включает его.

Чат и скины используют собственные `chat.enabled` и `skins.enabled`;
авторизация — `auth.mode`, голосования о нарушениях — `votes.enabled`.
Карта и навигация используют `map.enabled`; дополнительные ограничения —
в [настройках карты](map.md). Сетевой API и серверный рендер включаются отдельно
в разделах `[api.http]`, `[api.websocket]` и `[api.terrain]`.
TAB и имена над головой настраиваются независимо в `[display]`.
Интеграции с установленными поддерживаемыми модами подключаются автоматически.

## Сводка администратора

Откройте меню сервера → **Администрирование → Обзор**. Здесь собраны обращения,
ожидающие проверки метки и территории, ошибки Rivet и проблемы публикации сборки.
Карточка публикации открывает её проверку; общий пункт «Публикации карты» — всю очередь.
Сводка показывает до шести публикаций, а счётчик учитывает все ожидающие записи.

Данные обращений, диагностики и Builder выдаются только при соответствующих правах
`rivet.reports`, `rivet.diagnostics` и `rivet.pack`. Отключённая раздача сборки не
считается ошибкой публикации. Права проверяются повторно перед отправкой ответа.
