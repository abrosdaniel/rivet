# Команды и права

В командах статистики игрок указывается ником или серверным UUID; при неоднозначном имени нужен UUID. Команды Auth принимают ник.

| Команда                                                   | Действие                                                 |
| --------------------------------------------------------- | -------------------------------------------------------- |
| `/rivet`                                                  | Открыть меню.                                            |
| `/rivet help [раздел]`                                    | Справка по доступным командам.                           |
| `/rivet share <раздел> <id>`                              | Отправить доступную запись в чат.                        |
| `/rivet open <раздел> <id>`                               | Открыть запись; команда вызывается ссылкой в чате.       |
| `/rivet compatibility`                                    | Состояние серверных адаптеров и причины недоступности.   |
| `/rivet status`                                           | Состояние Rivet, БД, Auth и интеграций.                  |
| `/rivet player info <игрок>`                              | UUID, статус и статистика.                               |
| `/rivet reports`                                          | Последние пять обращений; ответы — в меню.               |
| `/rivet announce <текст>`                                 | Разовое объявление.                                      |
| `/rivet announce urgent <текст>`                          | Критическое предупреждение администрации.                |
| `/rivet announce pin <минуты> <текст>`                    | Закрепить сообщение на 1–10080 минут.                    |
| `/rivet announce unpin`                                   | Убрать закрепление.                                      |
| `/rivet maintenance on <минуты> <причина>`                | Ограничить новые входы на 0–1440 минут; `0` — бессрочно. |
| `/rivet maintenance off`                                  | Выключить обслуживание.                                  |
| `/rivet restart <секунды> <причина>`                      | Сохранить мир и остановить сервер через 1–86400 секунд.  |
| `/rivet restart cancel`                                   | Отменить запланированную остановку.                      |
| `/rivet auth rename <старыйНик> <новыйНик>` | Сменить ник офлайн-аккаунта с сохранением UUID; консоль или администратор. |
| `/rivet auth reset <игрок>`                               | Выдать приглашение на восстановление.                    |
| `rivet auth reserve <игрок>`                              | Закрепить свободное имя; только консоль.                 |
| `rivet auth block <игрок>` / `rivet auth unblock <игрок>` | Заблокировать / разблокировать аккаунт; только консоль.  |

Обслуживание не отключает уже вошедших игроков, администраторы могут подключаться. **Повторный запуск после `/rivet restart` выполняет служба запуска или панель управления сервером** — включите автоматический перезапуск.

## Исправление статистики

Работает для существующих игроков в сети и вне сети. Изменения записываются в журнал.

```text
/rivet stats show Player
/rivet stats time set Player 120h30m
/rivet stats time add Player 5h
/rivet stats time subtract Player 30m
/rivet stats since set Player 2026-09-01
/rivet stats deaths set Player 12
```

Время — целые часы `h` и минуты `m`, итог неотрицательный. Дата — `YYYY-MM-DD` по времени сервера, не в будущем. Дата и время игры меняются независимо; текущая сессия учитывается, дальнейшая игра начисляется к новому итогу. Общее время влияет на допуск к голосованиям о наказаниях.

## LuckPerms

OP уровня 2 и `rivet.admin` дают административный доступ. Для отдельных функций выдавайте права при установленном LuckPerms:

| Право                                   | Доступ                                            |
| --------------------------------------- | ------------------------------------------------- |
| `rivet.stats.view` / `rivet.stats.edit` | Просмотр / изменение статистики командами.        |
| `rivet.announce`                        | Объявления и закрепление.                         |
| `rivet.maintenance` / `rivet.restart`   | Обслуживание / остановка.                         |
| `rivet.reports`                         | Обращения, ответы и закрытие.                     |
| `rivet.diagnostics`                     | Состояние Rivet и интеграций.                        |
| `rivet.permissions.manage` | Изменение прав групп в меню Rivet; дополнительно нужен административный доступ. |
| `rivet.map.seeHiddenPlayers` | Просмотр скрытых игроков на карте и миникарте; входит в административный доступ. |
| `rivet.map.teleport`                   | Телепортация с карты без OP.                      |
| `rivet.pack`                            | Проверка и публикация клиентской сборки.           |
| `rivet.events`                          | Управление событиями.                             |
| `rivet.auth.reset`                      | Восстановление Auth; отдельное право даже для OP. |
| `rivet.vote.protected`                  | Защита от голосований о наказании.                |

Пример: `/lp group moderator permission set rivet.reports true`. Меню и команды проверяют права на сервере; `rivet.admin` также открывает журнал и экспорт.

Телепортация с карты: `/lp user <ник> permission set rivet.map.teleport true`. Право учитывает контекст LuckPerms и `*`; явный запрет `rivet.map.teleport=false` перекрывает wildcard для игрока без OP. Оно не выдаёт доступ к ванильной `/tp` или административному меню. OP уровня 2 сохраняет доступ; само по себе `rivet.admin` не заменяет отдельное право. Пункт карты обновляется без переподключения, а сервер заново проверяет доступ при каждом запросе. Модуль карты должен быть включён, игрок — авторизован.

## Управление из игры

Откройте **Администрирование → Права ролей**. Выберите группу LuckPerms:
список показывает понятные названия прав, а подсказка — назначение,
технический ключ и итоговый доступ группы без контекста мира.

Для редактирования выдайте администратору отдельное право:

```text
/lp user <ник> permission set rivet.permissions.manage true
```

OP уровня 2 также может редактировать права. Само по себе `rivet.admin`
открывает просмотр, но не управление правами.

Нажмите на право и выберите **Разрешить**, **Запретить** или **Наследовать**,
затем подтвердите изменение. «Наследовать» убирает прямое назначение из группы:
доступ определят родительские группы и остальные правила LuckPerms.
Административные возможности, включённые в `rivet.admin`, сохраняются при
отдельном запрете — это указано в подсказке права.

Rivet сохраняет изменения непосредственно в LuckPerms. Команды `/lp` и
редактор LuckPerms работают с теми же данными; открытое окно обновляется
автоматически. Если другой администратор уже изменил выбранное назначение,
сохранение отклоняется до обновления списка.

Редактор Rivet изменяет только постоянные глобальные права Rivet в загруженных
группах. Создание групп, назначение игроков, наследование групп, временные и
контекстные права настраиваются в LuckPerms. Персональные права и контекст мира
могут изменить доступ конкретного игрока. Без LuckPerms доступен только просмотр.

## Просмотр скрытых игроков

Администраторы видят скрытые позиции на игровой карте и миникарте.
Отдельному сотруднику можно выдать это право без полного административного доступа:

```text
/lp user <ник> permission set rivet.map.seeHiddenPlayers true
```

Право обходит настройки «Скрыто», «Только рядом» и выбранную аудиторию,
но не меняет сохранённые предпочтения игрока. Оно не отключает фильтры
невидимости и наблюдателя, не открывает позиции офлайн-игроков и само по себе
не расширяет доступ REST/WebSocket. Сервер проверяет право перед отправкой координат.
