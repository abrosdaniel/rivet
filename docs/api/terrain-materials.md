# Материалы серверной карты

Серверный рендер читает ресурсы Minecraft 1.21.1 без клиентского рендера и OpenGL.
Снимки содержат состояния блоков и окраску биомов; модели и текстуры обрабатываются
в рабочих потоках. Установка ресурсов и выбор профилей описаны в
[настройках рендера](../server/terrain-projections.md#ресурсы-серверной-карты).

## Источники ресурсов

Сначала читаются ресурсы установленных модов, затем ZIP/JAR и каталоги из
`rivet/terrain-resources/`. Локальные источники перекрывают предыдущие в порядке
имён файлов. Каждый содержит `assets/<namespace>/blockstates`, `models` и `textures`.
Клиентский JAR Minecraft 1.21.1 может служить локальным источником ванильных ресурсов.
Владелец сервера отвечает за право использования файлов.

Символические ссылки не принимаются. Rivet не скачивает и не распаковывает архивы,
не обращается за текстурами в сеть и не выдаёт исходные ресурсы через API.
Ресурсы перечитываются при перезапуске сервера, а не через `/reload`.

Содержимое ресурсов и ревизии поставщиков моделей определяют поколение кэша.
Изменённый во время работы файл вызывает отказ разрешения ресурса, чтобы не смешать
поколения. После изменения файлов перезапустите сервер и повторите рендер.
PNG и маскированные снимки сохраняются между запусками; палитры содержат имена
блоков, а не временные числовые идентификаторы Minecraft.

## Модели и текстуры

Поддерживаются стандартные JSON-модели NeoForge 1.21.1:

- наследование, ссылки на текстуры, прямоугольные элементы, UV и повороты граней;
- поворот и масштабирование элементов, повороты состояния блока и UV lock;
- варианты состояний, multipart, условия AND/OR и альтернативные свойства;
- корневые преобразования и вложенные `neoforge:composite`;
- цвет `neoforge_data.color` у элемента или грани.

Взвешенный вариант выбирается по координатам Minecraft, включая Y и отрицательные
значения. Выбор стабилен на границах тайлов и после перезапуска; кэш хранит выбранные
композиции, а не отдельную модель для каждой координаты.

Альфа PNG задаёт отверстия и прозрачность. `tintindex` использует сохранённую окраску
травы, листвы или воды; для других блоков применяется белый цвет, если поставщик
модели не задал свой. Анимированная текстура представлена первым указанным кадром.
Full-bright отключает направленное затенение. Динамический свет Minecraft,
промежуточные уровни освещения и ambient occlusion не воспроизводятся.

Жидкости учитывают уровень, уклоны по соседним углам и текстуры потока.
Внутренние грани непрерывной жидкости не рисуются. Затопленные блоки сохраняют
свою модель и добавляют поверхность воды. Вода окрашивается биомом и прозрачна,
лава непрозрачна. Соседи читаются только из маскированных снимков; отсутствующие
чанки не загружаются. Появление снимка соседа обновляет смежные тайлы.

При отсутствии ресурса, неизвестном загрузчике моделей или динамической сущности
блока используется куб с цветом палитры, если нет серверного поставщика геометрии.
Клиентские шейдеры, связанные текстуры, скрипты ресурспаков и рендер сущностей блоков
не запускаются. Для нестандартных жидкостей также нужен серверный поставщик.

## Проекции и прозрачность

| Проекция | Координаты при уровне 0 | Размер PNG |
| --- | --- | --- |
| Поверхность | `U = 16*x`, `V = 16*z` | 256×256 на чанк |
| Изометрия с материалами | `U = 8*(x-z)`, `V = 4*(x+z)-8*y` | 256×256 |
| Изометрия без материалов | `U = 2*(x-z)`, `V = x+z-2*y` | 256×256 |
| Пещерный обзор | `U = x`, `V = z` | 16×16 на чанк |

Всегда читайте `projection` из метаданных выбранного профиля. Для уровня N делите
проекционные координаты на `2^N`, затем на размер PNG с округлением вниз для
индекса тайла; остаток с неотрицательным результатом даёт координату пикселя.
Начало проекции соответствует мировой точке (0, 0, 0).

Рендер проверяет глубину граней, использует направленное затенение и выборку
ближайшего пикселя текстуры. На пиксель сохраняются ближайшая непрозрачная
поверхность и до восьми прозрачных слоёв. Отверстия показывают геометрию ниже.
Обзорные уровни усредняют цвет с учётом альфы; неизвестный или скрытый исходный
пиксель оставляет объединённый пиксель скрытым.

## Серверные поставщики моделей

Реализуйте `dev.abros.rivet.api.TerrainMaterialProvider` и укажите класс в
`META-INF/services/dev.abros.rivet.api.TerrainMaterialProvider`. Поставщики
подключаются при запуске рендера и сортируются по уникальному `id()` с пространством
имён. Для неподдерживаемого блока возвращайте `Optional.empty()`: далее используются
следующий поставщик и JSON-модель. Ошибка поставщика записывается в диагностику.

`model(String block, Map<String,String> properties)` возвращает неизменяемые
`Model`, `Quad`, `Vertex` и `Texture`. XYZ задаются в блоках, UV — нормализованные.
Порядок вершин направляет грань наружу; доступны окраска биома и направленное
затенение. Прозрачность задаётся ARGB-пикселями. Геометрия должна лежать в [-1, 2]
по каждой оси. Текстуры копируются при передаче. Меняйте `revision()` при изменении
геометрии или текстур, чтобы обновлялось поколение тайлов.

Вызовы могут поступать из рабочих потоков: реализация должна быть быстрой,
потокобезопасной и детерминированной. Это доверенный Java-код одной JVM.
Контракт не передаёт живой мир, сущность блока или клиентский менеджер ресурсов;
используйте статическую серверную геометрию.

## Лимиты и диагностика

| Ресурс | Ограничение |
| --- | --- |
| Локальные источники | 64; до 200 000 записей при обходе каждого |
| Действующие ресурсы | 100 000 файлов, суммарно 512 МиБ |
| Один ресурс / JSON модели | 4 МиБ / 1 МиБ |
| Вложенность JSON / цепочка родителей | 64 / 32 |
| Multipart и варианты / элементы / грани модели | 128 / 64 / 384 |
| Вложенность composite / дочерние модели | 16 / 64 |
| Кэш планов выбора | 64 определения JSON |
| Исходный PNG | До 512×8192 и 4 194 304 пикселей; кадр до 512×512 |
| Кэш моделей | 4096 записей и 64 МиБ; одна модель до 16 МиБ |
| Кэш текстур | 16 777 216 пикселей, 64 МиБ ARGB |
| Очередь изометрии | 8 заданий |
| Изометрический тайл | До 250 000 записей палитры или 1 500 000 текстурированных граней |

Закрытые непрозрачные кубы пропускаются с учётом фактически выбранных моделей
соседей. Слишком сложный тайл завершается ошибкой, не заменяя готовый PNG.
Отмена останавливает дальнейшую обработку; замена завершённых PNG атомарна.
`maxTiles` отдельно ограничивает PNG профилей и сохранённые снимки чанков.
Ресурсы закрываются вместе с модулем; выключенный рендер их не открывает.

`TerrainApi.materials()` и метаданные REST возвращают активность, количество
ресурсов, счётчики разрешения моделей и до 100 диагностических примеров.
Счётчики отражают компиляции, включая повторные после вытеснения из кэша,
а не количество блоков мира. В диагностике есть ID и причины, но нет путей файлов.
Для REST требуется `map.tiles.read` и доступ к выбранному профилю.
