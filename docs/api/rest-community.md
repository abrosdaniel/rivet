# Объединения и расписания

Участники, заявки, внутренние метки и повторяющиеся события.

Для всех маршрутов нужны сессия игрока и право приложения. Пути указаны
относительно `/api/v1/`.

| Маршрут | Право ключа | Доступ и результат |
| --- | --- | --- |
| `GET groups/{id}/members` | `groups.read` | UUID, имя и роль; видимость как у игрового списка участников |
| `GET groups/{id}/applications` | `groups.read` | Управляющим — заявки с текстом; остальным — только своя |
| `GET groups/{id}/invitations` | `groups.read` | Управляющим — приглашения; остальным — только свои |
| `GET groups/{id}/markers` | `groups.read` | Внутренние места; только действующим участникам |
| `POST groups/{id}/actions/markerSave` | `groups.write` | Создание или изменение метки управляющим |
| `POST groups/{id}/actions/markerDelete` | `groups.write` | Удаление метки управляющим |
| `GET events/{id}/schedule` | `events.read` | Время и доступные события серии; приглашённые — только владельцу |
| `GET admin/server/announcements` | `server.control.read` | До 50 ожидающих объявлений; дополнительно `rivet.announce` |
| `POST admin/server/announcements` | `server.control.write` | Планирование объявления; дополнительно `rivet.announce` |
| `POST admin/server/announcements/{id}/cancel` | `server.control.write` | Отмена объявления; дополнительно `rivet.announce` |

## Страницы объединения и метки

Ответ списка содержит `items`, `revision` объединения и `nextCursor`, до 20 записей.
Курсор связан с игроком, объединением и видом списка. При изменении объединения
ответ `409` требует начать с первой страницы. Право ключа не заменяет членство
или роль управляющего; доступ проверяется и при обновлении подписки.

Данные сохранения метки: `{itemId,itemRevision,title,description,location}`.
При создании передайте `itemId: ""`, `itemRevision: 0`; при изменении — ID и
ревизию метки. Удаление принимает `{itemId,itemRevision}`. В `If-Match` нужна
ревизия **объединения**, а квитанция возвращает ID и ревизию **метки**.
После изменения перечитайте список. Название — до 100 символов, описание — до 1000.
Места всегда доступны только участникам; эти маршруты не изменяют задачи.

## Повторяющиеся и частные события

`POST events` принимает `{title,description,startsAt,capacity}` либо эти же поля
со всеми дополнительными параметрами внутри `data`:

```json
{
  "visibility": "invited",
  "group": "",
  "invitees": "",
  "durationMinutes": 60,
  "repeat": "weekly",
  "occurrences": 8,
  "timezone": "Europe/Warsaw"
}
```

- `visibility`: `public`, `group` или `invited`. Для `group` автор должен состоять
  в указанном объединении.
- `invitees`: до 30 известных UUID или имён через запятую; UUID исключает неоднозначность.
- `durationMinutes`: 1–1440 минут.
- `repeat`: `none`, `weekly`, `fortnightly` или `monthly`; для серии — 2–26 событий.
- `timezone`: часовой пояс IANA, сохраняющий местное время при переходе на летнее время.

Создание серии атомарно; повтор исходной операции не создаёт вторую серию.
Действуют `rivet.events`, ограничения контактов и лимиты событий.

## Отложенные объявления

Создание принимает `{text,startsAt}`: текст 1–500 символов, время ISO от 10 секунд
до 30 дней вперёд. Отмена принимает `{}` и числовую ревизию в кавычках в `If-Match`.
Обе операции используют общую оболочку команды. Для изменения расписания отмените
запись и создайте новую. Повтор не публикует объявление дважды; офлайн-сотрудники
проходят ту же проверку прав, что при других административных действиях.
