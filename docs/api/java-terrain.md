# Управление рендером

Профили, тайлы и задания через Java API.

`api.terrain()` возвращает `TerrainApi`; при выключенном рендере — ошибка
`MODULE_DISABLED`. Это серверная карта, независимая от исследования клиента.
Java API предназначен для доверенных модов и не проверяет сетевые права ключей.
Не открывайте его внешним пользователям без собственной авторизации.

| Метод | Назначение |
| --- | --- |
| `profiles()`, `profile(id)` | Список и выбор общего или приватного профиля |
| `metadata()`, `projection()`, `slice()` | Идентификатор мира, поколение кэша, границы, проекция и пещерный диапазон |
| `tile(new TerrainApi.Tile(dimension, zoom, x, z))` | Асинхронное чтение сохранённого PNG с хешем; отсутствующий тайл — `NOT_FOUND` |
| `cursor()`, `changes(cursor)` | До 256 последних изменений тайлов |
| `render(new TerrainApi.Region(dimension, minChunkX, minChunkZ, maxChunkX, maxChunkZ))` | Рендер включительной области до 4096 загруженных чанков |
| `renderSaved()` | Обход сохранённых регионов в разрешённых границах без загрузки и генерации чанков |
| `jobs()`, `job(id)`, `cancel(id)` | Очередь, прогресс и отмена задания |
| `materials()` | Состояние ресурсов и диагностика моделей |

У каждого профиля собственные кэш, поколение и курсор; очередь рендера общая.
Поверхность и изометрия используют тайлы 256×256, пещеры — 16×16.
Для поверхности и пещер тайл уровня N покрывает `16 * 2^N` блоков по каждой оси.
X направлен на восток, Z — на юг; отрицательные координаты делите с округлением вниз.
Изометрическую проекцию всегда читайте из метаданных. Формулы и ограничения —
в [справочнике материалов](terrain-materials.md).

Получите курсор до чтения тайлов. При `RESYNC_REQUIRED` после перезапуска или
переполнения истории перечитайте метаданные и курсор, затем проверьте свой кэш.
Для пещер `slice()` содержит включительные `minY`/`maxY`; у других проекций он пуст.

Состояния задания: `QUEUED`, `READING`, `CAPTURING`, `WRITING`, `COMPLETE`,
`CANCELLED`, `FAILED`. Во время поиска сохранённых чанков `total = -1`, после
обхода — число просмотренных позиций (`rendered + skipped`). Пустые позиции
и чанки без статуса `minecraft:full` пропускаются. Ошибки NBT или чтения завершают
задание без замены готовых тайлов повреждёнными данными.

Отмена прекращает дальнейшую обработку; начатое чтение или запись PNG может
завершиться. Не ждите futures через `join()` на игровом потоке. При остановке
сервера интерфейсы становятся недействительными: подключитесь заново, затем
получите сохранённые задания по их ID.

Настройки, квоты, маски и восстановление описаны в
[руководстве по серверному рендеру](../server/terrain.md).
Проверки контракта и нагрузочные сценарии — в [проверках API](../development/api-testing.md).
