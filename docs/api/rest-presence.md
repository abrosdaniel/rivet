# Игроки на карте

Присутствие, приватность позиций и доступные Waystones.

Эти чтения требуют ключа и сессии игрока, который сейчас онлайн и авторизован
в игре. Офлайн-читатель получает `403`. Анонимного доступа и административного
обхода приватности нет. Ответы — текущие снимки, без истории координат.

| GET-маршрут | Право ключа | Поля записи |
| --- | --- | --- |
| `players/online` | `players.presence.read` | `uuid`, `name` |
| `map/positions` | `map.positions.read` | `uuid`, `name`, `dimension`, `x`, `y`, `z` |
| `map/waystones` | `map.waystones.read` | `uuid`, `name`, `dimension`, `x`, `y`, `z` |

Ответ — `{items,nextCursor}`, до 64 записей. Необязательный `dimension` фильтрует
измерение; `cursor` продолжает список после последнего видимого UUID. Движение
и изменения доступа могут менять следующие страницы. Для нового снимка начните
с первой. Курсор не раскрывает скрытые UUID.

Присутствие и позиции описывают других игроков, исключая читателя, наблюдателей,
неавторизованных и невидимых ему игроков. Действуют игровые правила видимости
карты, расстояния и общего членства в объединениях. Одновременное изменение
приватности может вернуть `409`: повторите чтение. Выключенная карта или передача
позиций запрещает доступ.

Waystones возвращает только доступные этому игроку точки по правилам установленного
адаптера. Он не активирует камни и не телепортирует игрока. Отсутствующий или
неподдерживаемый адаптер возвращает `503 / MODULE_DISABLED`; ошибка адаптера
не открывает доступ. Наличие `map.read` не заменяет отдельные права из таблицы.

WebSocket поддерживает подписки на эти маршруты. Без изменений БД снимки
перепроверяются примерно раз в пять секунд. При закрытии подписки или потере
сессии приложение должно удалить отображаемые приватные данные.

## Слои сторонних модов

`GET /api/v1/map/layers` и
`GET /api/v1/map/layers/{owner}/{layer}/objects` читают временные Java-регистрации.
Ключу требуется `map.read`; сессия игрока необязательна. Без неё доступны только
явно публичные слои и объекты, с ней — пересечение аудиторий слоя и объекта.
Скрытый слой возвращает 404. REST не создаёт и не изменяет регистрации модов.

Параметры `cursor` и `snapshot` обеспечивают продолжение страницы (до 64 слоёв
или 8 объектов). Используйте значения из ответа; изменение реестра возвращает
409 и требует чтения с первой страницы. Отключение владельца удаляет его данные,
выключение карты очищает весь реестр. Контракт описан в OpenAPI.
