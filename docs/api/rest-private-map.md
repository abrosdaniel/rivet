# Приватные карты

Доступ к профилям, кэширование и пещерные срезы.

`GET /api/v1/map/terrain/profiles` возвращает `profiles: [{id, private, projection}]`,
отфильтрованные по правам ключа. Во всех terrain-маршрутах параметр `profile`
принимает `surface`, `isometric` или ID настроенного приватного профиля. Метаданные
возвращают выбранный `profile`; `projection.profile` обозначает тип проекции.

Для приватного ID нужен точный scope `map.tiles.profile.<id>` дополнительно к
`map.tiles.read` (либо `map.render.manage` для управления рендером). Сессия игрока
не требуется. Запрет действует на metadata, PNG, events/cursor и операции очереди;
проверка прав происходит до выбора кэша и перед выдачей прочитанного изображения,
включая условный GET. Очередь заданий общая для всех профилей.

Ключи кэша разделены по профилю и поколению маски; ETag включает мир, поколение
профиля и содержимое. Приватные PNG: `Cache-Control: private, no-store`,
`Vary: Authorization`. Cursor одного профиля нельзя использовать в другом;
при изменении конфигурации/перезапуске получите metadata и новый cursor.
Нельзя обслуживать файлы `rivet-terrain` напрямую через CDN или статический маршрут.
Браузер получает PNG через backend сайта, где остаётся постоянный API-ключ.

## Пещерные слои

Пещерный профиль выбирается обычным параметром `profile`, например
`GET /api/v1/map/terrain?profile=deep_caves`. Он требует точного scope
`map.tiles.profile.deep_caves` и `map.tiles.read`, как любой приватный профиль.
Проекция в metadata — `cave` (оси x/z, 16 пикселей), поле `slice` содержит
включительные `minY`/`maxY`. Список `/map/terrain/profiles` также включает `slice`
только у разрешённых пещерных профилей. Параметров произвольного Y/диапазона в URL нет:
фиксированные слои настраивает владелец сервера, чтобы ограничить данные и кэш.

Маршруты PNG/events/jobs остаются теми же. Отсутствующая полость изображается
прозрачными пикселями; ещё не отрендеренный тайл — `NOT_FOUND`. Смена слоя требует
его metadata и cursor; переносить курсор/ETag другого профиля нельзя. При смене
диапазона меняется generation. Приватный cache policy и повторная проверка прав
перед условным GET применяются к пещерам без исключений.

Проверка под нагрузкой и в браузере: [изолированный стенд API](../development/api-testing.md).

Настройка TLS: [HTTPS/WSS через reverse proxy](../server/reverse-proxy.md).
