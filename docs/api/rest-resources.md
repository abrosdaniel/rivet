# Ресурсы и действия

Чтение и изменение данных игроков и сообщества.

Основные ресурсы: `groups`, `events`, `board`, `polls`, `ideas`, `tasks`,
`profiles`, `notifications`, `chat` и объекты `map`. Чтение требует соответствующего
права `*.read`, запись — `*.write`. Точные пути и поля задаёт OpenAPI.
Публичные записи сообщества и опубликованная карта доступны по ключу;
личные данные и изменения требуют также сессию игрока.

Маршруты следующей таблицы начинаются с `/api/v1`. Кроме `pack`, им требуется сессия игрока.
Права приложения не заменяют игровые права связанного аккаунта.

| Ресурс | Scope | Доступ |
| --- | --- | --- |
| `GET reports`, `GET reports/{id}` | `reports.read` | Собственные обращения, без служебных заметок и диагностики |
| `POST reports` | `reports.write` | Создание обращения с `message`, `category` |
| `GET admin/reports`, `GET admin/reports/{id}` | `reports.manage` | Дополнительно текущее `rivet.reports`; фильтры `filter`, `cursor` |
| `POST admin/reports/{id}/actions/{action}` | `reports.manage` | `reply`, `claim`, `release`, `assign`, `classify`, `state`, `note` |
| `GET statistics/{id}` | `statistics.read` | Приватность профиля и разрешённые владельцем поля; сохранённые показатели без внутреннего session ID |
| `GET skins/{id}` | `skins.read` | Приватность профиля; только UUID, hash и slim текущего скина |
| `GET pack` | `pack.read` | Опубликованный hash, Minecraft/loader, число файлов и описания компонентов; без файлов, путей, URL и установщика |
| `GET admin/map/objects` | `moderation.manage` | Текущее `rivet.admin`, включая черновики для модерации |
| `POST admin/map/objects/{id}/{action}` | `moderation.manage` | `approve`, `reject`, `withdraw`; текущее `rivet.admin` |
| `GET/PUT me/notification-preferences` | `notifications.read/write` | Собственные `muted`, `snoozeUntil`; PUT требует content revision |
| `POST chat/messages` | `chat.write` | `channel`, `text`; автор определяется сессией |

Административные действия доступны офлайн. Онлайн-права проверяются с текущим
контекстом игрока; офлайн LuckPerms загружает пользователя и применяет статический
серверный контекст, без координат или выдуманного мира. OP уровня 2 сохраняет
штатные права. Нет LuckPerms и OP — административный доступ запрещён.
Управление API-ключами остаётся исключительно в локальной серверной консоли.

`POST groups`, `board`, `events`, `polls`, `ideas` создают записи. Создание событий
требует `rivet.events`, голосований — `rivet.admin`. У существующих записей доступны
`actions/edit`, `delete`, `restore` по штатным правилам владельца. Объединения также
поддерживают приглашения, отзыв приглашения, рассмотрение заявки, принятие приглашения,
изменение роли участника и переключение приёма заявок. События — перенос и отмену; доска — решение по
отклику и отзыв отклика. Точные поля каждой операции перечислены в OpenAPI.

Задачи поддерживают `assign`, `due`, `comment`, `restore`, `dependencies`, `repeat`,
`reserve`. Изменения требуют текущего `If-Match`; создание — нет. Все команды используют
одинаковые `operationId`, `issuedAt`, `data` и атомарные квитанции повторного запроса.

Чат отправляется как обычный текст с префиксом `[API приложение] Имя:`, без имитации
подписи Minecraft, click/hover-компонентов и выполнения команд. Лимит — 5 сообщений
за 10 секунд на игрока независимо от приложения. Очередь доставки ограничена 1024
сообщениями, срок живой доставки — 60 секунд. Общий и групповой каналы доступны офлайн;
групповой требует действующего членства. Локальный требует онлайн-авторизации и
реальных получателей рядом; их список повторно ограничивается при доставке.
История сохраняется в той же транзакции, если она включена. После аварии между
доставкой и подтверждением очереди возможен повтор живого сообщения; повтор API-запроса
с прежним operationId не создаёт второе сообщение. При отключённом чате доставка
приостанавливается, просроченные записи удаляются при возобновлении.

## Подзадачи и действия сообщества

Доступны команды задач `subtask-add`, `subtask-edit`, `subtask-toggle`,
`subtask-remove`, `resources`. Индекс относится к текущей ревизии задачи; для
страницы подзадач учитывается `subtaskOffset`. `GET tasks/{id}/details` возвращает
исполнителя, срок, страницы комментариев/подзадач и требования ресурсов.
Параметры `subtaskOffset`, `commentOffset` задают страницу, необязательный `revision`
защищает переход между страницами от изменения задачи. Не более 20 подзадач и
комментариев на страницу и 30 требований ресурсов.

Доступны действия `events/{id}/actions/reminder` (minutes: -1,0,5,15,60),
`cancelSeries`; `groups/{id}/actions/removeMember` (target,reason),
`assistantRemoval` (enabled), `territory` (territory или null). Название территории
задаётся объединением. У board/events/polls/ideas доступно действие `location`
с location или null. Действие `hide` для общественных документов и `ideas/.../status`
требуют дополнительно текущего `rivet.admin`; одного права ключа на запись недостаточно.
Обычные операции сохраняют ограничения владельца/руководителя/участника.
