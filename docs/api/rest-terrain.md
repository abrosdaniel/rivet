# Тайлы и задания рендера

Получение PNG и управление рендером сохранённого мира.

Рендер не зависит от исследованной карты клиента. Чтение PNG не загружает и
не генерирует чанки; отсутствующий тайл возвращает NOT_FOUND.

| Метод и путь | Назначение |
| --- | --- |
| GET `/api/v1/map/terrain` | Метаданные, проекция, материалы и cursor |
| GET `/api/v1/map/terrain/profiles` | Только доступные ключу профили |
| GET `/api/v1/map/terrain/tile.png` | PNG по dimension, zoom, x, z |
| GET `/api/v1/map/terrain/events` | Изменения после stream/after |
| GET/POST `/api/v1/map/terrain/jobs` | Очередь или рендер указанной области |
| POST `/api/v1/map/terrain/jobs/saved` | Полный рендер сохранённых чанков |
| GET/DELETE `/api/v1/map/terrain/jobs/{id}` | Состояние или отмена задания |

Чтение требует `map.tiles.read`, управление заданиями — `map.render.manage`.
Параметр `profile` выбирает surface, isometric или именованный приватный профиль;
для приватного нужен также `map.tiles.profile.<id>` конкретного ключа.
Очередь заданий общая и предназначена для административного управления.
Метаданные задают геометрию проекции: не вычисляйте изометрические координаты
по правилам поверхности. Поверхность и изометрия используют PNG 256px;
пещерные профили — фиксированные диапазоны высоты с обзором 16px.
Приватные PNG имеют `private, no-store`; маски применяются до сохранения тайлов.
Ограничения материалов описаны в [серверном рендере](terrain-materials.md).
