# Другие моды

Возможности Rivet при установленных совместимых модах.

Rivet автоматически подключает поддерживаемые установленные моды:

| Мод                         | Возможности                                                |
| :-------------------------- | :--------------------------------------------------------- |
| LuckPerms                   | Права, префиксы и суффиксы игроков                         |
| Plasmo Voice                | Голосовая модерация и диагностика подключения              |
| Simple Voice Chat           | Голосовая модерация и диагностика подключения              |
| Waystones                   | Доступные игроку камни на карте и миникарте                  |
| Create: Access Denied       | Совместимость списков доступа с аккаунтами Rivet           |
| Create: Numismatics         | Имена владельцев счетов и карт с учётом аккаунтов Rivet     |
| Envelope                    | Почта сохраняется за владельцем после смены ника          |
| spark                       | Диагностика производительности для администрации           |

Камни Waystones появляются автоматически: открытые игроком, общедоступные и доступные его команде. Смена видимости, названия и удаление отражаются на карте при следующем обновлении (обычно до двух секунд). Иконка использует модель и текстуры предмета Waystones с учётом ресурспака. Нажатие позволяет начать маршрут; активация и телепортация остаются в Waystones. Камни не копируются в личные метки.

Эти моды устанавливаются отдельно. Для передачи своей позиции участникам объединения нужно согласие игрока; история позиций не сохраняется. Настройка и диагностика интеграций описаны в [серверном справочнике](../server/integrations.md#необязательные-интеграции).
