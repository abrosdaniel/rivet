# Поделиться местом

Есть два способа: отправить копию метки в чат или опубликовать объект для всего сервера.

## Отправить метку в чат

Поделитесь личной меткой в общем чате. Получатель нажимает ссылку и подтверждает добавление.
У него появится независимая копия: ваши дальнейшие изменения её не затронут.

## Опубликовать для всех

1. Откройте редактор личной метки или территории.
2. У метки нажмите значок публикации рядом с закрытием окна. У территории — **«Сохранить и отправить на проверку…»**.
3. В карточке публикации отправьте заявку.
4. После одобрения администрации объект получит статус **«Видно всем»**.

Исследованная местность не передаётся. Другие игроки видят только опубликованную метку или контур.

## Изменить или убрать публикацию

Откройте карту (**M** по умолчанию) → **«Список меток»** → **«Мои публикации»**.
Здесь находятся ваши заявки и опубликованные объекты обоих типов: метки и территории.

Найдите объект по названию или фильтру статуса и откройте его карточку.

| Действие | Результат |
| --- | --- |
| Изменить опубликованный объект | Изменения снова проходят проверку. До одобрения всем видна прежняя версия. |
| Отменить заявку | Объект больше не находится на проверке. |
| Снять с публикации | Объект сразу исчезает с общей карты. Личная копия остаётся. |

Автор может иметь до **50** активных заявок и публикаций.
[Серверные ограничения](../server/map.md#личные-и-общедоступные-объекты).

## Проверить заявки администратору

1. Откройте меню Rivet (**F8**) → **«Администрирование»** → **«Публикации на карте»**.
2. Очередь открывается с фильтром **«На проверке»**. Для уже опубликованных объектов смените фильтр справа от поиска.
3. Откройте карточку → **«Название, автор и координаты…»**. Если автор меняет уже
   опубликованный объект, сравните правки через **«Версия, которую сейчас видят все…»**.
4. Нажмите **«Одобрить»** или **«Отклонить правки»** и подтвердите действие.

Для проверки нужны административные права Rivet. Обычный игрок может управлять
своими заявками, но не одобрять их. Отклонение новых правок сохраняет прежнюю
опубликованную версию объекта.
