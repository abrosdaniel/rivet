# Меню сервера

Откройте меню клавишей **F8**. Назначение клавиши можно изменить в настройках управления Minecraft.

| Раздел | Назначение |
| --- | --- |
| Главная | Закреплённое объявление, ваши объединения и избранные действия |
| Игроки | Поиск, профили и доступная статистика |
| Объединения | Участники, заявки, приглашения, территория и общие метки |
| Помощь | Информация и ссылки владельца сервера |
| Администрирование | Инструменты, доступные по вашим правам |

Уведомления открываются из шапки меню. Набор доступных инструментов зависит от
настроек сервера и ваших прав. Для общения используйте [чат](chat.md), для передачи предметов — [обмены](trading.md).

Поиск в меню находит доступные действия, игроков, объединения и внутренние метки
объединений. Введите хотя бы два символа. Выбор внутренней метки открывает вкладку
«Метки» её объединения; чужие закрытые метки не выдаются в результатах. Действия открывают соответствующий
раздел; административные инструменты доступны только сотрудникам с нужными правами.
Поиск также находит загруженные личные и общедоступные метки карты. Выбор
переносит карту к месту; личные координаты не отправляются на сервер для поиска.

Локальные действия остаются доступны, даже если серверный поиск временно не отвечает.

Откройте **Настройки → Общие → Виджеты главной**. Включите нужные
быстрые действия и перетащите их за ручку справа, чтобы изменить порядок.
Выбор сохраняется на этом клиенте. Недоступные на текущем сервере действия
скрываются; после возврата доступа снова появляются.

## Объединение: где искать действия

Откройте **F8 → Объединения → карточка объединения**.

- **Посетитель:** подайте заявку на вкладке «Обзор» или ответьте на приглашение.
  После отправки заявки здесь же доступны её статус и отзыв. Уведомление сообщает,
  принята она или отклонена.
- **Участник:** вкладка «Метки» содержит внутренние места объединения.
  Они доступны участникам и администраторам.
- **Помощник:** вкладка «Заявки» позволяет рассматривать заявки и приглашения.
  Исключение участников доступно, только если лидер разрешил его помощникам.
- **Лидер:** на вкладке «Участники» можно назначить помощника или передать лидерство.
  Передача требует подтверждения. Ваша роль указана на вкладке «Обзор».

При выходе из объединения доступ к внутренним меткам прекращается.
Действия с территорией находятся на вкладке «Обзор»; это отдельный сценарий от
[публикации личных объектов карты](publishing.md).

## Уведомления

Откройте уведомления из шапки меню и выберите запись. Кнопка возврата из карточки
возвращает к тому же списку уведомлений. Если объект удалён или доступ отозван,
переход недоступен; текст уведомления остаётся во входящих. Прочтение не даёт
дополнительных прав.

В настройках уведомлений можно отключить всплытия отдельных источников, включая
сторонние моды, или включить тихий режим на час. Записи остаются во входящих.
Объявление сервера открывает информацию о сервере, а ответ по публикации карты —
вашу публикацию.

## Обращения для модератора

**F8 → Администрирование → Поддержка → очередь обращений**. Достаточно права
`rivet.reports`; полный административный доступ не требуется. Выберите обращение,
назначьте ответственного, ответьте игроку и при необходимости закройте его.
Дополнительный фильтр «Все», «Без ответственного» или «Высокий приоритет» указан
на кнопке фильтра. На последней странице можно вернуться к началу списка.
