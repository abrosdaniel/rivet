# Меню сервера и задачи

Игроки, объединения, события и задачи доступны в меню F8.

| Раздел            | Назначение                                                         |
| :---------------- | :----------------------------------------------------------------- |
| Главная           | Сводка, закреплённое объявление, ближайшие события и задачи        |
| Игроки            | Поиск игроков, профили, статистика и последняя активность          |
| Мои задачи        | Личные задачи; задачи объединения доступны внутри объединения      |
| Доска объявлений  | Публикации, покупка, продажа и обмен                               |
| Объединения       | Участники, заявки, общие задачи и места                            |
| События           | Встречи, запись, очередь участников и напоминания                  |
| Голосования       | Решения сообщества и разрешённые сервером голосования о нарушениях |
| Предложения       | Идеи игроков и обсуждение                                          |
| Помощь            | Текст помощи и ссылки владельца сервера                            |
| Администрирование | Сводка и инструменты для игроков с соответствующими правами        |

Доступные разделы определяет сервер. Уведомления открываются из шапки меню. Личные сообщения используют чат Minecraft; отдельного мессенджера Rivet нет.

## Ресурсы и склады задач

Для задачи можно указать предметы и требуемое количество, затем привязать контейнер табличкой с тремя строками:

```text
&rivet
Название объединения или ник владельца личной задачи
Код задачи, например 7K2P
```

Код задачи остаётся прежним при переименовании. Привязку выполняет владелец личной задачи или управляющий объединения. Rivet учитывает содержимое загруженных контейнеров; для выгруженных показывает последнее подтверждённое состояние и время проверки, без дополнительной прогрузки чанков.


## Объединение: где искать действия

Откройте **F8 → Объединения → карточка объединения**.

- **Посетитель:** подайте заявку на вкладке «Обзор» или ответьте на приглашение.
  После отправки заявки здесь же доступны её статус и отзыв. Уведомление сообщает,
  принята она или отклонена.
- **Участник:** «Задачи» и «Метки» содержат внутренние записи объединения.
  Они доступны участникам и администраторам. Личные задачи остаются в «Мои задачи».
- **Помощник:** вкладка «Заявки» позволяет рассматривать заявки и приглашения.
  Исключение участников доступно, только если лидер разрешил его помощникам.
- **Лидер:** на вкладке «Участники» можно назначить помощника или передать лидерство.
  Передача требует подтверждения. Ваша роль указана на вкладке «Обзор».

При выходе из объединения доступ к внутренним задачам и меткам прекращается.
Действия с территорией находятся на вкладке «Обзор»; это отдельный сценарий от
[публикации личных объектов карты](publishing.md).

## События и уведомления

**F8 → События → карточка**: запишитесь на событие или встаньте в очередь, если
места закончились. Положение в очереди показывается в карточке. Здесь же можно
отменить участие и выбрать напоминание. Для задачи или события без координат
маршрут не предлагается.

Откройте уведомления из шапки меню и выберите запись. Кнопка возврата из карточки
возвращает к тому же списку уведомлений. Если объект удалён или доступ отозван,
карточка сообщает об отказе; прочитанное уведомление не даёт дополнительных прав.

## Обращения для модератора

**F8 → Администрирование → Поддержка → очередь обращений**. Достаточно права
`rivet.reports`; полный административный доступ не требуется. Выберите обращение,
назначьте ответственного, ответьте игроку и при необходимости закройте его.
Дополнительный фильтр «Все», «Без ответственного» или «Высокий приоритет» указан
на кнопке фильтра. На последней странице можно вернуться к началу списка.
