# Установить сборку сервера

Rivet показывает состав сборки, загружает выбранные компоненты и применяет их после закрытия игры.
Minecraft, NeoForge и сам Rivet устанавливаются отдельно.

## Первая установка

1. Подключитесь к серверу. При первом обращении подтвердите его ключ. Если ранее сохранённый ключ изменился, сначала уточните это у владельца.
2. Выберите необязательные компоненты. Обязательные отмечены постоянно; полное описание компонента доступно при наведении.
3. Просмотрите добавления, замены и удаления, затем подтвердите установку.
4. Дождитесь загрузки и закройте Minecraft кнопкой в окне Rivet.
5. После применения файлов запустите игру своим лаунчером и подключитесь снова.

В окне видны этап, прогресс и объём загрузки. При повторном подключении уже установленные файлы повторно скачивать не нужно.

## Изменить компоненты

В списке сетевой игры выберите сервер и нажмите **«Сборка»** рядом с подключением.
Измените выбор и проверьте обзор изменений. Выбор сохраняется отдельно для каждого сервера.
Если файлы не меняются, перезапуск не нужен. Уже подготовленное обновление сначала нужно завершить.

## Перейти на другой сервер

Rivet предлагает заменить управляемые файлы прежней сборки. Настройки конфигов, установленных сборкой, сохраняются отдельно для каждого сервера и восстанавливаются при возвращении.
Личные конфиги, существовавшие до установки, остаются общими. При одинаковом наборе файлов можно подключаться сразу.

## Если обнаружен конфликт

Проверка перечислит несовместимые версии, отсутствующие зависимости или дубликаты модов.
Измените выбор компонентов либо состав личных модов и повторите проверку.
Rivet не удаляет личный дубликат автоматически и останавливает установку до изменения игровых файлов.

??? info "Что происходит с моими файлами"

    Rivet удаляет только файлы, которыми управляла установленная сборка. Дополнительные личные моды можно оставить, если они совместимы.
    Перед заменой и удалением создаётся резервная копия. Изменённые управляемые файлы отмечаются в обзоре — установку можно отменить.

    Личные конфиги по умолчанию сохраняются. Явные замены задаёт владелец сервера; они также видны в обзоре.
    Файлы без компонента обязательны и показаны по имени файла.

??? info "Откуда скачиваются файлы"

    Моды по ссылкам сначала загружаются с Modrinth или CurseForge. Если источник недоступен или проверка файла не пройдена, используется копия сервера.
    Локальные файлы сборки загружаются с сервера.

    Неиспользуемые загрузки старше семи дней удаляются из кэша при запуске. Незавершённые установки, резервные копии и настройки серверов сохраняются.
