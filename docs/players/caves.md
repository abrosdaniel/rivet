# Пещерная карта

Откройте **Шестерёнка на карте → Пещерная карта**. Здесь настраивается подземный вид большой карты и миникарты.
Сервер может запретить пещерные слои.

## Выбрать режим

| Режим | Что показывает |
| --- | --- |
| Выкл. | Только поверхность |
| По слоям | Срез на выбранной высоте с заданной глубиной |
| Вся глубина | Первый открытый пол под грунтом без ограничения глубины |

Большая карта по умолчанию следует автоматическому режиму миникарты.
Автоматика проверяет потолок над игроком; листва, жидкости и прозрачные блоки потолком не считаются.
При открытом небесном свете пещерный режим не включается.

## Задать высоту вручную

Введите **верхний Y**. Значение применяется сразу; `Auto` или пустое поле возвращает автоматический выбор.
Для режима **«По слоям»** выберите глубину среза. В режиме **«Вся глубина»** ручной Y и глубина не используются.
Новая метка получает высоту выбранного слоя.

## Значения по умолчанию

| Настройка | Значение |
| --- | --- |
| Проверка потолка миникарты | 3×3 |
| Глубина среза | 30 блоков |
| Интервал между переключениями | Не менее 1 секунды |
| Масштаб пещерной миникарты | 2× |
| Освещение по глубине | Выключено |

??? info "Точные настройки автоматики и среза"

    Проверка потолка: 1×1, 3×3 или 5×5. Большая карта может следовать миникарте или использовать отдельную настройку.
    Задержки настраиваются отдельно: 0–10 секунд с шагом 0,1 секунды. Первое включение и отслеживание высоты внутри пещеры не задерживаются.

    Режим «По слоям» хранит диапазоны по 16 блоков. Верхний Y определяет срез внутри диапазона; глубина 1–64 включает верхний блок.
    Поиск пола начинается после воздуха или жидкости под потолком. Неверный Y сохраняет последний допустимый срез.

    Освещение по глубине меняет яркость относительно высоты среза. Пустой исследованный столбец выглядит тёмным, а не неисследованным.
    Масштаб миникарты доступен от 1× до 4×; показ верхнего Y можно отключить.
    Клавиша ручного режима назначается в управлении Minecraft и использует выбранный Y или высоту над игроком при Auto.

Поверхность и пещеры сохраняются отдельно, только из уже полученных клиентом чанков.
Срез запоминается для мира и измерения; настройки автоматики, задержек и масштаба общие.
