# Управление и интерфейс

Основные клавиши и поведение окон Rivet.

На сервере меню открывается **F8** или командой `/rivet`.
Для быстрой смены скина используется **F7**.
Клавиши переназначаются в управлении Minecraft. **Esc** закрывает меню,
**Backspace** закрывает основной раздел или возвращает из вложенного окна;
в поле ввода удаляет символы.

Начальный масштаб GUI — 3. Изменённый игроком масштаб сохраняется.
Виджет включён по умолчанию; его расположение, содержимое и видимость настраиваются.
Клиентские настройки общие для всех серверов.
