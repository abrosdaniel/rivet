# Разработка Rivet

## Подготовка

Нужен JDK 21. Используйте Gradle Wrapper из репозитория;
системная установка Gradle не требуется.

## Сборка и тесты

```sh
./gradlew build
```

Сборка проверяет Java-модули и формирует комплект мода.
Серверные тесты PostgreSQL запускаются отдельно:

```sh
./gradlew :core:postgresTest
```

Подключение тестовой БД задаётся переменными `RIVET_TEST_DB_HOST`,
`RIVET_TEST_DB_PORT` и `RIVET_TEST_DB_PASSWORD`. Используйте отдельную тестовую базу.

Проверки инструментов упаковки и публикации:

```sh
python3 -m pip install -r rivet/tooling/requirements.txt
python3 -m unittest discover -s rivet/tooling/tests
```

## Автоматические проверки

Обычные push и pull request проверяют сборку на Linux, PostgreSQL 18 и инструменты.
Новая версия в основной ветке проходит полную матрицу Linux/Windows/macOS,
PostgreSQL 17/18, сценарии интерфейса Minecraft и запуск/остановку серверных
модулей. Публикация выполняется только после успешного завершения полной матрицы.
Полную проверку можно также выбрать в Actions → Build and test → Run workflow.
Повторная проверка уже отмеченной тегом версии не публикует её заново.

CI не сохраняет скриншоты. При неудаче доступны логи сценариев и Minecraft.
TAB проверяется с пустым, небольшим и большим списками игроков на GUI 1/2/3.
Серверные сценарии проверяют обычные настройки, выключенные чат/скины/Auth
и базовую авторизацию; тестовые данные хранятся в отдельной PostgreSQL.

## Структура

- `rivet/core` — логика, независимая от Minecraft.
- `rivet/mod` — серверные и клиентские возможности NeoForge.
- `rivet/bootstrap` — загрузка комплекта мода.
- `rivet/helper` — вспомогательный процесс установки и обновления файлов.
- `rivet/tooling` — проверка, упаковка и публикация сборок.

## Интерфейс

Экраны используют общие компоненты [UI Kit](docs/development/ui-kit.md).
Проверяйте длинные подписи, небольшие окна, светлые темы,
клавиатурную навигацию и ошибки сохранения.
Тестовые сценарии включаются параметром `-PrivetUiHarness`;
они не входят в выпускаемый JAR. `RIVET_UI_SCREENSHOTS=false` отключает
сохранение PNG, сохраняя проверки поведения и геометрии.

## Версии и совместимость

Версия задаётся один раз: `rivetVersion` в `gradle.properties`.
Описание текущего выпуска — `rivet/RELEASE_NOTES.md`.

- **PATCH** — исправления, оптимизация, тесты и документация.
- **MINOR** — новые функции и настройки с сохранением конфигурации и данных.
- **MAJOR** — несовместимые изменения, требующие действий владельца сервера.

Клиент и сервер должны иметь одинаковую MAJOR-версию; полный номер клиента
не может быть ниже серверного. Версии сетевых протоколов проверяются отдельно,
необязательные возможности согласуются при подключении. Изменение протокола
требует новой MAJOR-версии; совместимый номер протокола не отменяет ограничения
по версии клиента.

Публикация использует проверенный CI-комплект, формирует `core.json` и
`SHA256SUMS.txt`. Выпущенные версии не перезаписываются.

## Изменения

Опишите проблему, результат и выполненные проверки в pull request.
Для ошибок приложите версию Minecraft, NeoForge и Rivet, шаги воспроизведения
и относящиеся к ошибке строки лога. Удалите пароли и другие секреты из вложений.
