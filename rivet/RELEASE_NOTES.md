# Rivet 2.12.0

## Интерфейс

- Меню сервера, вложенные окна, карта, HUD и гардероб используют общий UI Kit с рендером Skia: сглаженные текст, иконки, скругления и тени.
- Сохранены управление с клавиатуры, темы, настройки доступности и нативное управление предметами. В обменах по-прежнему можно выбрать оформление Minecraft.
- Исправлены высота вкладок, центрирование подписей, цвет инструментов карты в светлой теме и выделение текста. Колесо внешности использует общие сглаженные сектора.
- Исправлен переход целой строки на пиксельный шрифт при наличии специальных символов: резервный рендер используется только для отдельных символов.
- Убраны полосы на полупрозрачных виджетах HUD при дробном масштабе и тёмный след при затухании наведения.
- Подсказка чата описывает каналы Rivet и их настроенные триггеры; команды Minecraft `/msg`, `/w`, `/tell` из неё убраны.
- Библиотеки рендера и шрифт включены в JAR; отдельная установка и скачивание при запуске не требуются.

## Оптимизация

- Уменьшен размер универсального JAR: общие данные Windows не дублируются для двух архитектур. Все шесть платформ остаются в комплекте.
- Убрана повторная установка одинаковых преобразований при отрисовке текста и элементов UI.
- Игровые проверки CI начинают работу после Linux-сборки; UI распределён по независимым группам. Полный набор релизных проверок сохранён.

## Официальные плащи

- Сервер получает официальный плащ вместе со скином Mojang согласно `skins.fallback` и передаёт его клиентам Rivet, в том числе для локальных UUID Auth.
- Официальный плащ отображается в гардеробе и на персонаже, сохраняется между перезапусками и не расходует лимит загруженных плащей.
- Сохранены переключение между официальным и пользовательским плащом, скрытие, текстуры элитр и стандартные крылья для PNG без рисунка элитр. При ошибке получения профиля сохраняется последняя загруженная внешность.

Установка остаётся одним JAR для клиента и сервера. Minecraft 1.21.1, Java 21,
NeoForge от 21.1.250 в ветке 21.1. Перед обновлением сохраните базу данных и мир.
Для использования новых серверных данных плащей обновите клиент и сервер до 2.12.0.
