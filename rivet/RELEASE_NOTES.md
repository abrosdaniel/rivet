# Rivet 1.0.0

- Полное переименование продукта: Rivet, идентификатор `rivet`, пакеты `dev.abros.rivet`, команда `/rivet`, настройки `rivet-server.toml`, каталог данных и схема PostgreSQL `rivet`.
- Обязательные компоненты сборки показаны неизменяемыми строками с замком и пояснением; переключатели доступны только для необязательных компонентов.
- Новый пиксельный логотип: медная заклёпка с цинковым стержнем. Логотип и название Rivet расположены по центру шапки меню.
- Масштаб GUI 3 применяется один раз при первом запуске; дальнейший выбор игрока сохраняется.
- Шаблон семени использует `rivet.json` и требование `rivetVersion = "1.0.x"`.
