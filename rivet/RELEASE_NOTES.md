# Rivet 2.10.0

- Исправлено отключение клиента с Brewin’ and Chewin’ при получении и отправке личных сообщений через `@Ник: текст`, `/msg`, `/w` и `/tell`.
- Адаптер сохраняет эффект B&C, зелёное оформление личного канала и направление сообщения. Стандартная доставка Minecraft и подписи сообщений не меняются.
- Обязательная проверка обновления и окно выбора версий запрашивают свежий каталог. Сохранённый после сетевой ошибки каталог помечается как неполный; отсутствие подходящего выпуска подтверждается только полной проверкой.
- Ошибки проверки обновлений показывают версии клиента, сервера и платформы. Подробности сетевой ошибки сохраняются в журнале; повторный запрос обновляет каталог, соблюдая срок ограничения источника.

- Добавлен подписанный статический каталог с резервным адресом и зеркалами файлов. GitHub API остаётся запасным источником.
- Builder раздаёт проверенный официальный JAR работающего сервера через существующие прямые и прокси-маршруты. Обновление Rivet и сборки требует одного перезапуска.
- Ограничения запросов сохраняются между запусками; повторная проверка не обходит Retry-After. Подпись и SHA-256 проверяются независимо от источника.
