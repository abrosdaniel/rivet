# Rivet 2.2.0

## Карта и навигация

- Личные территории с редактированием контура и цвета. Территории объединений сохраняют свои права и автоматически используют название объединения.
- Общедоступные метки и территории с модерацией. До одобрения изменений игроки видят предыдущую опубликованную версию; автор может снять объект с публикации.
- Обмен личными метками через общий чат: получатель добавляет независимую копию после подтверждения.
- Отдельное право LuckPerms `rivet.map.teleport` для телепортации с карты без OP. Доступ проверяется при каждом запросе; ванильная `/tp` от этого права не становится доступной.
- Исправлены повторная загрузка карты при открытии, устаревшее затемнение чанков, сохранение пещерного контекста и обработка Esc во вложенных окнах.
- Уменьшена миникарта по умолчанию; размер меток по умолчанию — 50%. Скорректированы размеры радара и контуры точек. Сохранённые настройки игрока остаются прежними.
- Ускорен отбор видимых чанков и территорий. Публичные объекты обновляются частично, с ограничением размера сетевых страниц и восстановлением полного снимка при необходимости.

## Сборки и безопасность

- Совместимые стабильные версии NeoForge допускаются в ветке 21.1 от 21.1.250 с проверкой требований всех выбранных модов. Minecraft остаётся 1.21.1, Java — 21.
- Добавлены настройки `[pack.protection]`: ограничения соединений с одного адреса, частоты запросов, ожидания очереди и зависшего ввода-вывода. Они автоматически добавляются в конфиг с комментариями и резервной копией; значения владельца сохраняются.
- Повторные запросы файлов больше не вызывают неограниченное повторное хеширование. Входящие запросы меню, скинов и Waystones ограничиваются до разбора JSON и помещения в очередь игрового потока.
- Проверка публичных HTTPS-адресов выполняется непосредственно при установлении соединения; сохранены проверка TLS и ограничения загрузок. PostgreSQL-драйвер обновлён до 42.7.14.
- Исправлено сохранение выбора компонентов без файловых изменений: оно не оставляет пустую незавершённую установку и не блокирует следующий запуск.
