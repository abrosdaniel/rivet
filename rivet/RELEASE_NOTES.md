# Rivet 2.4.1

- Исправлена проверка версий и загрузка файлов с GitHub: длинные заголовки ответа больше не прерывают обновление. Ограничения размера и количества заголовков сохранены.
- Кнопка «Повторить» выполняет новую проверку после сбоя без ожидания истечения кэша ошибки.
- При ошибке проверки окно больше не показывает «Нет доступных версий». Техническая причина записывается в журнал клиента.

- Исправлена гонка фоновой подготовки страниц карты: результат, рассчитанный до изменения блока, больше не публикуется поверх новых данных и не перезаписывает сохранённый предпросмотр.

Если установленная версия не может загрузить обновление, закройте Minecraft и замените JAR Rivet в папке `mods` новым файлом. Не оставляйте две версии мода одновременно. Данные и настройки Rivet сохраняются.
