# Rivet 2.5.2

- Устранено переключение головы на стандартный скин во время фонового обновления владельца. Подтверждённый профиль сохраняется до получения ответа сервера.
- При смене скина прежняя текстура остаётся видимой до загрузки новой. Уже выданные и установленные головы обновляются без повторной выдачи.
- При возврате к обычному скину голова использует восстановленный UUID владельца, а не старый UUID предмета. При переподключении устаревшее состояние очищается. Декоративные головы с явно заданной текстурой сохраняют её.

Для полного набора исправлений голов используйте 2.5.2 на сервере и клиентах. Команда выдачи не изменилась. Старую голову со встроенной чужой текстурой нужно выдать заново по имени: такие данные нельзя надёжно отличить от декоративной головы.
