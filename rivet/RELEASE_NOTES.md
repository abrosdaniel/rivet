# Rivet 2.1.1

- Исправлена ошибка `OverlappingFileLockException` при сохранении выбора компонентов, когда файлы сборки уже установлены. Сохранение больше не оставляет пустое незавершённое обновление, блокирующее следующий запуск Minecraft.
- Исправлен тот же сценарий при переходе между серверами с одинаковыми файлами сборки.
- Команда проверки сборки отдельно показывает количество обязательных и необязательных компонентов.
