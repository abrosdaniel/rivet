# Rivet 1.1.0

## Для игроков

- Новый TAB с головами, метаданными LuckPerms, группировкой, стандартными полосками связи и настройкой фона. Убран повторный счётчик игроков.
- Чат рядом, общий чат и чат объединений: `[канал] | голова префикс ник суффикс: сообщение`. Названия каналов задаёт сервер.
- Чат использует обычный ввод Minecraft без вставки предметов и ручных статусов.
- Стандартное автодополнение объединений при вводе `#`, кликабельные координаты `[pos]`.
- Поиск настроек, светлые и цветные темы, предпросмотр и общий редактор HUD. Блоки виджета можно переставлять перетаскиванием.
- Временная навигация работает при открытом чате; точки из сообщений называются «Место от Ник». При прибытии удаляются указатель и метка Xaero’s.
- Маршрут действует до прибытия или ручной остановки. Кнопка × на указателе доступна в чате и режиме курсора; ограничения по времени нет.
- Общий режим курсора для TAB и виджета. Точный пинг и время сессии по умолчанию выключены; масштаб GUI 3 применяется только при первом запуске.
- Исправлены размещение страницы сервера и голограммы хранилищ. Кнопка «Скины» открывает библиотеку, горячая клавиша — быструю смену.

## Для владельцев серверов

- Необязательные интеграции LuckPerms, Plasmo Voice, Xaero’s, Create: Access Denied и spark подключаются автоматически через адаптеры. Ошибки одного адаптера изолированы.
- Панель spark: TPS, MSPT, CPU, память, графики, профилирование и история отчётов. Административные предупреждения приходят через уведомления Rivet.
- Сервер определяет использование чата Rivet, названия каналов, доступные вставки, радиус локального чата и режим TAB.
- Добавлены лимиты задач, этапов и комментариев; `0` отключает соответствующий лимит. Большие задачи открываются страницами, существующие записи сохраняются.
- Пороги нагрузки и интервал предупреждений spark настраиваются в серверном конфиге.
- Добавлены явные требования версии семени: `>=1.1.0 <2.0.0` и `=1.1.0`; старые записи сохраняют прежний смысл.
- Обновлены описание мода, серверный справочник и пояснения к конфигурации.

## Установка и обновление

Minecraft 1.21.1, Java 21, NeoForge от 21.1.250 в ветке 21.1. Для серверных функций нужна PostgreSQL. Обновите Rivet на сервере и клиентах для использования всех новых возможностей. Семена ветки `1.x` остаются совместимыми; для обязательного использования новых возможностей укажите `rivetVersion = ">=1.1.0 <2.0.0"` (новый синтаксис читается с 1.1.0).
