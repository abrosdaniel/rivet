# Rivet 2.0.2

## Интерфейс

- Выбор компонентов серверной сборки использует чекбоксы в компактном списке.
- Обязательные файлы отображаются с установленной галочкой и недоступны для отключения.
- Подсказки показывают описание компонента или полный путь обязательного файла. Недоступные строки обозначены приглушённым цветом.
