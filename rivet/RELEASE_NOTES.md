# Rivet 1.3.2

## Для игроков

- Исправлено отображение игроков в TAB: записи не пропадают при распределении по колонкам.
- Прокрутка TAB корректно учитывает выбранное сервером оформление и не перехватывает управление стандартным списком игроков.
- Исправлено размещение длинных значений пинга; неизвестный пинг обозначается прочерком.
- При отключении от сервера очищаются цели взаимодействия TAB и данные навигации.

## Для владельцев серверов

- Функции разделены на внутренние модули с управляемым запуском и остановкой. Rivet по-прежнему устанавливается одним JAR.
- Улучшено освобождение ресурсов серверных модулей при остановке и ошибках запуска.
- Ошибки обмена скинами теперь отражаются в диагностике с ограничением повторяющихся записей.
- Обновлена документация для игроков, владельцев серверов и разработчиков.
