# Rivet 2.0.1

## Исправления

- Проверка сборок принимает вложенные библиотеки в любых безопасных относительных путях внутри JAR, включая `META-INF/jars`. Исправлены ложные ошибки для LambDynamicLights и Supplementaries.
- Контейнеры библиотек NeoForge обрабатываются отдельно от вложенных модов. Исправлена ложная ошибка повторяющегося Sodium.
- Типы зависимостей читаются без учёта регистра. Учтены обязательные зависимости по умолчанию и штатная матрица совместимости NeoForge для Minecraft 1.21.1.
- Ошибки вложенных JAR указывают файл мода и путь библиотеки. Проверки опасных путей, конфликтов и отсутствующих зависимостей сохраняются.
