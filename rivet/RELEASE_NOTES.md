# Rivet 2.6.0

- Большие клиентские карты используют региональный индекс вместо полного списка чанков. Повторное открытие читает готовый индекс; исходные тайлы сохраняются в прежнем формате.
- Ошибки чтения меток, категорий и территорий больше не блокируют друг друга. Неудачные записи сохраняются для повторной попытки; сообщения об ошибках снимаются после восстановления.
- При подключении совместимые обновления Rivet и сборки объединяются в один обзор, одну установку и один перезапуск. При сбое применения откатывается весь набор файлов.
- Требования сервера к Rivet проверяются до игрового подключения. Частичная загрузка списка версий явно отмечается. Проверяются свободное место, исходные файлы и состояние установки.
- Открытие меню не запускает повторное синхронное хеширование сборки. Адресные изменения обновляют HUD без ожидания очередного опроса.
- Обход складов ограничен загруженными чанками и бюджетом работы. Очередь дискового кэша скинов ограничена и очищается при смене подключения.
- Серверный рендер сохраняет задания при временном отказе журнала и повторяет запись с увеличением интервала.

Предварительная проверка подключения поддерживается серверами этой версии. Клиенты без неё сохраняют прежний экран несовместимости. Minecraft и NeoForge обновляются через лаунчер; исследованная карта остаётся на клиенте.
