# Rivet 2.7.0

- Раздача сборки поддерживает несколько TCP-маршрутов: приоритет по игровому адресу, резервные подключения и продолжение прерванной загрузки с проверкой ключа сервера и хеша файла. Старые host/publicPort сохраняются.
- Подтверждённые адреса одной раздачи используют общий выбор компонентов. Ошибки подключения показывают адреса; проверку можно повторить из окна сборки.
- При тайм-ауте или ошибке TLS соединение закрывается без повторной отправки через повреждённый канал.
- Добавлен автоматический клиентский адаптер Brewin’ and Chewin’: эффект опьянения совместим с оформлением общего чата Rivet. Исправлено отключение при обработке сообщения.
