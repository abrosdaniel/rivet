# Rivet 1.0.0

- Полное переименование продукта: Rivet, идентификатор `rivet`, пакеты `dev.abros.rivet`, команда `/rivet`, настройки `rivet-server.toml`, каталог данных и схема PostgreSQL `rivet`.
- Установочные файлы и инфраструктура обновлений используют имя Rivet и репозиторий `abrosdaniel/rivet`.
- Обязательные компоненты сборки показаны неизменяемыми строками с замком и пояснением; переключатели доступны только для необязательных компонентов.
- Первый самостоятельный выпуск: требуется ручная установка клиента и сервера, обновление конфигурации и перенос существующих данных перед первым запуском. Смешивание с предыдущей веткой не поддерживается.
