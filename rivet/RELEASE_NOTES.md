# Rivet 2.3.0

## API и интеграции

- Добавлен типизированный Java API для сторонних модов: чтение, изменения и подписки на доменные данные, собственные слои и объекты карты.
- REST и WebSocket предоставляют доступ к объединениям, событиям, объявлениям, голосованиям, предложениям, задачам, профилям, уведомлениям, чату и карте. Доступ учитывает отключённые модули, приватность и права игрока; административные операции поддерживают офлайн-сотрудников.
- API-ключи создаются и управляются только из локальной консоли сервера. Для личных данных доступны вход через Auth Rivet и привязка через игру. Браузер подключается к WebSocket с одноразовым ticket без постоянного ключа.
- Встроенные адаптеры LuckPerms, голосовых модов, Waystones, spark и Create: Access Denied используют провайдеры Java API; подключение остаётся автоматическим.
- Добавлен адаптер Create: Numismatics: имена владельцев счетов и карт разрешаются через Java API Rivet с учётом Auth; балансы, UUID и права Numismatics сохраняются.
- Добавлены позиции игроков и доступные им Waystones с проверкой видимости и присутствия в игре.

## Серверный рендер карты

- Поверхность, изометрия и пещерные слои доступны через API без встроенного веб-интерфейса. Полный рендер читает сохранённые чанки без их загрузки в игровой мир и генерации новых.
- Очередь обновлений, планировщик и восстановление незавершённых заданий после перезапуска. Приватные профили и маски областей ограничивают выдачу тайлов и доступ к кэшу.
- Поддерживаются локальные ресурспаки, текстуры, статические модели блоков и жидкости. Неизвестные динамические модели требуют серверного поставщика геометрии; полное соответствие клиентским шейдерам не заявляется.

## Исправления и установка

- Исправлена проверка прав LuckPerms во время входа и выхода обычного игрока: она сохраняет игровой контекст до добавления в список онлайн и после удаления из него.
- Добавлен прогресс загрузки обновлений Rivet и сборки: процент, объём и число файлов; отдельные состояния проверки и подготовки установки.
- Улучшено восстановление сохранённого изображения клиентской карты при повторном входе и обновлении освещения.
- Исправлены отсчёт запланированной остановки сервера, повторный звук уведомлений, ограничение срочной очереди и подтверждение прочтения.
- Установка остаётся одним JAR. HTTP, WebSocket и серверный рендер выключены по умолчанию; новые настройки добавляются с сохранением существующих значений и резервной копией.
- Minecraft 1.21.1, Java 21, стабильная NeoForge 21.1 от 21.1.250. Для сервера 2.3.0 нужен клиент Rivet не ниже 2.3.0 в той же MAJOR-ветке. Перед обновлением сохраните резервную копию PostgreSQL и конфигурации.

## Документация

- Единый сайт с короткими руководствами для игроков, владельцев серверов и разработчиков. Тематическая навигация, поиск и отдельные справочники API; старый дублирующий серверный справочник удалён.
