# Rivet 2.12.1

- Builder устанавливает файлы из папок ресурсов модов, включая `emotes`, без фиксированного списка разрешённых папок.
- Сохранена защита личных и служебных данных, конфигурации Rivet, скрытых путей и символических ссылок. Конфликты с личными или изменёнными файлами требуют проверки перед установкой.
- Исправлено размещение префиксов и суффиксов в карточках TAB: две строки помещаются даже при компактной плотности; длинный текст сокращается, полное оформление доступно в подсказке.

Установка — одним JAR для клиента и сервера. Minecraft 1.21.1, Java 21,
NeoForge от 21.1.250 в ветке 21.1. Для дополнительных папок сборки обновите
клиент и сервер. Перед обновлением сохраните базу данных и мир.
